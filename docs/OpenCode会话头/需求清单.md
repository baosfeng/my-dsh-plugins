## 易碎点

- **handler 必须同步**：`llm/stream` waterfall handler 若写成 `async`，waterfall 返回 Promise 会破坏下游 `yield*` 委托（见 [踩坑：llm 流 async 处理器误用](../踩坑/llm流async处理器误用.md)）。
- **惰性发请求**：pi-ai 的 `Models.streamSimple()` 惰性——真正的 HTTP 发生在消费流时，故**每次** `next()`/`return()` 都必须在 `sessionContext.run()` 内执行，否则补丁读不到会话上下文。
- **不改 `options`**：`llm/stream` 的 options 可能被冻结，只能包装返回的流。
- **与静态 header 互斥**：`settings.yaml` 里写死的 `x-opencode-session` 会让插件（默认 `override: false`）等于没生效，且所有会话共用一个固定值；必须删除静态项或用 `override: true`。
- **卸载只摘自己那层**：`disposer` 仅在当前 `globalThis.fetch` 仍是自己装的那个时还原；被压在下层时从链上摘除自己（`LAYER_KEY` 标记），不触碰他人 patch。
- **配置非法即启动失败**：`providers` / `hosts` 空数组、非裸主机名、非法头名 / `valueMode` 均抛 `[opencode-session-header] config.xxx …`（不静默降级成"插件没生效但又没提示"）。
