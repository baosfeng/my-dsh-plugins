# Skill 管理（dsh-my-skill-manager）

> 源码：`plugins/dsh-my-skill-manager/` · [插件 README](../../plugins/dsh-my-skill-manager/README.md) · [文档索引](../索引.md)

## 功能

分「全局 / 项目」查看全部 skill（名称、描述、来源、状态），在设置页一键启用 / 禁用——被禁用的 skill 不再注入该项目会话，模型不可见也不可加载；配置随仓库版本化。

## 安装

```bash
dsh plugin --profile web add dsh-my-skill-manager --trust-lockfile
```

## 配置

| 位置                                   | 作用                           |
| -------------------------------------- | ------------------------------ |
| 项目根下的 `.dsh/skills.enabled.json`  | 项目级禁用名单（随仓库版本化） |
| 用户级 `$DSH_HOME/skills.enabled.json` | 全局禁用名单                   |

只维护禁用名单（`enabled` 白名单模式预留未实现）。

## 主要能力

- 列表合并官方 skill catalog 与插件侧目录扫描：目录存在但 catalog 缺失的条目补充显示并标记「未收录」；
- 面板顶部「全局 / 当前项目」分段切换，项目视图只显示项目来源 skill，可编辑项目级配置（含在项目内禁用全局 skill）；
- 新建 skill 后点「刷新」立即可见，修改即时生效、无需重启；
- 「扫描诊断」折叠条列出 frontmatter 异常、符号链接失效等未被官方扫描器收录的条目及原因。

## 边界

- 禁用按名字生效：同名的任何来源 skill（项目 / 用户 / 内置）都会被占位覆盖；
- 项目配置以 cwd 向上找最近 `.git` 定位项目根，无 `.git` 时退回 cwd 自身；
- 只扫描插件侧可确定的默认根目录，宿主自定义 skill 目录不纳入（宁可漏报也不误报）。
