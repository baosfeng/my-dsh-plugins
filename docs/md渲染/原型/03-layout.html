围栏分流：先看语言，再看证据

本插件接管对话里的全部围栏块，分流的依据是三源互补：client 侧会话事件流索引（含历史、命中即零 RPC）→ host 侧实时围栏语言索引 → DOM 契约（code.language-* / banner infostring）。判定结果里的 confirmed 只用来区分「确证无语言」与「识别失败」；确证无语言时再看内容（像 markdown 文档才 markdown 化，否则代码卡），不猜语言。

分流规则

围栏语言渲染路径产物
text / md自研 markdown 渲染div.mdr-md：真实 h1–h6 / table / blockquote
确证无语言看内容分流像 markdown 文档 → markdown；否则代码卡（保留换行、语言位留空）
js / ts / json / bash自研代码块语言胶囊 + highlight.js + 复制 + 换行切换
mermaid / mmd图表卡片预览 / 代码切换 + 导出 PNG / SVG + 浮窗缩放
识别失败代码视图语言位留空（绝不编造语言名）
  • 语言索引命中 → 零 RPC
  • DOM 契约兜底 → 零额外请求
  • 内容启发式判定 —— 明确不做
  • 未命中时的降级提示 —— 待定

「绝不编造语言名，也绝不把真纯文本误判成 markdown。」—— 分流的第一原则
