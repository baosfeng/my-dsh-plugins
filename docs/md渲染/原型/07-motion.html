本插件接管对话里的全部围栏块，分流的依据是三源互补：client 侧会话事件流索引（含历史、命中即零 RPC）→ host 侧实时围栏语言索引 → DOM 契约（code.language-* / banner infostring）。判定结果里的 confirmed 只用来区分「确证无语言」与「识别失败」，不做内容启发式判定。旧写法 按内容猜语言 已废弃。

相关说明见 列表与嵌套；识别不出语言时语言位留空（裸链接会退化成纯文本样式）。raw HTML 一律当字面文本处理：<div class="note">。
