# md 渲染（dsh-md-render）

> 源码：`plugins/dsh-md-render/` · [插件 README](../../plugins/dsh-md-render/README.md) · [文档索引](../索引.md) · [渲染原型](原型/README.md)

## 功能

对话里的**围栏代码块全部由本插件自己的渲染器产出**（不再调用宿主官方 `MarkdownText` / `CodeBlock`），官方节点结构一个字节都不改（只追加自有容器 + 自有 CSS 在接管视图下隐藏官方子树）：

- **自研 markdown 渲染**：`text` / `plaintext` / `txt` / `md` / `markdown` 围栏块、**确证无语言**的围栏块、`pre[data-context-text]` 上下文注入正文（子 agent 回传消息 / AGENTS.md）、公共 API `MarkdownView` —— 解析层用 **marked**（GFM 表格 / 列表 / 标题 / 链接 / 行内代码 / 代码块），产出真实标签 + 自有 class，每块带独立「查看原文」；
- **自研代码块渲染**：`js` / `ts` / `json` / `bash` / `python` … —— banner 显示**真实语言名**（不是官方那个本地化标签「代码块」）+ 复制 + 自动换行 + **highlight.js** 高亮（hljs 令牌树 → 自有 vdom span，没有任何 innerHTML）；
- **mermaid 图表卡片**：`mermaid` / `mmd` 围栏块 → 图表卡片（预览 / 代码切换、导出 PNG / SVG、浮窗 + 缩放平移）；
- **「渲染为…」三态切换**（图表 / Markdown / 源码）对所有围栏块可用，覆盖值按内容哈希记入 `sessionStorage`；
- **整段复制**、**统一 MarkdownView**、**表格容错**（GFM 不认的两种分隔行写法先规范化）、**思考块默认展开**、**设置面板**。

**解析层与高亮层走 assets 懒加载**（与 mermaid 引擎同一模式）：`marked`（47 KB）与 `highlight.js`（129 KB）由 host 半静态托管于 `/md-render/assets`，client 首次真正需要时才 fetch + 注入 `<script>`，**不进 `lib/client.js`** —— 用户口径「打包体积不用控，只控启动速度」；就绪通知触发一次重扫补渲染。

## 外观（markdown 内容以原型为唯一真源）

markdown 内容的视觉设计**不再自行发挥**：唯一真源是[渲染原型](原型/README.md)（Apple 语义 token 样张，open-design 六阶段流水线产出）。插件侧是原型的**宿主内嵌落地**：

| 原型 | 插件落点 |
| --- | --- |
| apple 56 槽 `:root`（`--bg` / `--fg` / `--accent` …） | **不照搬十六进制**：同名语义映射到宿主 `--dsw-alias-*`，派生线索色用 `color-mix` 由宿主色算出来 |
| 几何 `8 / 12 / 18 / 980` | `--mdr-radius-sm\|md\|lg\|pill` 逐字一致 |
| 字号 `21 / 17 / 15 / 14 / 13 / 12` | `--mdr-fs-h1…h6` 逐字一致；**正文取宿主对话尺度**（见偏离 1） |
| 间距 `4 / 8 / 12 / 16 / 24` | `--mdr-space-1…6` 逐字一致 |
| `--motion-fast` / `--motion-base` / `--ease-standard` | `--mdr-motion-fast`(150ms) / `--mdr-motion-base`(220ms) / `--mdr-ease` |
| `--focus-ring`（4px 光晕） | `--mdr-focus-ring` + `-inset` 变体（给被 overflow 裁掉的滚动区） |
| `--mdr-line-accent` / `--mdr-tint-accent` / `--mdr-accent-text` / `--mdr-code-bg` / `--hairline` / `--scrim` | `--mdr-accent-line` / `--mdr-tint` / `--mdr-accent-text` / `--mdr-code-bg` / `--mdr-hairline` / `--mdr-scrim` |

遮罩改用**宿主的固定黑遮罩 token** `--dsw-alias-bg-mask-3`（`--mdr-scrim`）—— 修掉旧实现「拿正文色按比例混」在深色态**反相成白雾**的问题（原型 §D2 警告过的那片浅灰，只是成因不同：深色下 `label-primary` 是近白）；

**有意偏离**（原型的取舍不适用于「嵌在宿主对话流里」，逐条记录以免静默不对齐）：

1. 正文 **14px**（原型 17px 是独立网页尺度）—— 插件嵌在宿主对话流里，正文必须与宿主对话同尺度；标题阶梯仍逐字对齐原型；
2. 整段复制按钮**默认隐形**（hover / focus-within / 触屏三路浮现）—— 样张里常显是为了看样，对话流里常显会干扰阅读；
3. **颜色一律由宿主语义色取或 `color-mix` 派生**，不照搬 apple 十六进制（照搬会破宿主深浅色）；插值空间用 `srgb`（仓库既有口径），原型用 `oklab`，不混用两种空间；
4. **字体栈不硬编码 SF Pro**：宿主已提供系统 UI 字体栈，硬编码会在非 macOS 平台掉到 Helvetica / Arial；
5. **内容列宽（原型 720px）与平滑滚动归宿主**：属宿主消息区与宿主容器，插件不对宿主元素写 style / class；
6. **形状规则**（边框 / 圆角 / 阴影 / 内边距）**仍不在原型范围**；但**工具条控件层本轮已纳入原型**（`08-prototype.html` §sec-toolbar）—— 常驻三项、26px 方格、悬停浮层、菜单收纳都按原型实现。⚠️ 这里踩过两次：① 把「28px **文字胶囊**」写进共享控件规则 → 卡片头变松、按钮换行、标题胶囊被挤折行（用户真机截图暴露）；② 批量改文案时按整行替换，把「只是行的一部分」的语句连前缀一起吃掉（eslint 抓出 `find is not defined`）。「范围纪律」断言已改为「共享控件必须是 26px 方格」；
7. **阴影取宿主层级 token**（`--dsw-shadow-lv1` / `-lv2`）而不是原型的 `--elev-raised` 字面值 —— 阴影是宿主主题资产（深色下更弱），取宿主层级才有正确的深浅色表现。
8. **颜色类取值一律宿主语义 token**（遮罩 / 行内码底 / 发丝边 / 阴影），既不照搬原型十六进制、也不按原型比例混色 —— 按比例混色的**方向**在深色态会反转（见上一条遮罩）；
9. **任务框只读**（`disabled` + `readOnly`）：原型样张里可勾选是为了演示勾选态；插件里 markdown 是模型输出快照、勾选无法持久 —— 勾选态由 `:has(:checked)` 跟随**原文** `- [x]` 呈现，样式里因此**不写** `cursor` / `:focus-within`（写了就是永不触发的死规则）；
10. **灰阶四档并三档**：原型的 `fg-2` 与 `muted` 两档都落到宿主 `label-secondary`（次级的对比度安全档），`meta` 落到 `label-tertiary`（只给非文字元素，如任务框描边）—— 宿主只有三档，且原型自己实测过更浅那档对 12px 小字不达 4.5:1；
11. **复制按钮不再有可见文案**：文字走 `data-dsh-md-render-tip` 悬停浮层（原型 `.md-copy` 是「图标 + 文字」的 28px 胶囊 —— 本轮按用户口径「文字默认不显示、只展示图标」改为 26px 图标按钮），完整语义留在 `aria-label`「复制整段 markdown」；
12. **工具条只显示图标 + 低频操作收纳**（用户口径）：文字走 `data-dsh-md-render-tip` 悬停浮层（`::after` absolute、向下弹，**零布局位移**）；复制的成功 / 失败态浮层常显（状态不能只靠悬停）；触屏按钮就地带文字。**每个按钮都必须有图标** —— 已给共享图标集补 `maximize / fit / fill / minus / wrap / markdown / eye / chart / more` 九个。悬停属性用 `data-dsh-md-render-tip` 而**不是**裸 `data-tip`：宿主自己也用了 `data-tip`（`ui-agent-preset`），裸名会在同一页面上撞名；

原型 `08-checklist.md` §F 的两条待办在插件侧**不成立**：深色态不需要第二套取值（颜色全由宿主语义变量派生，`data-ds-dark-theme` 与系统偏好都自动跟随）；触屏点击区按桌面平台处理（原型同判 P1 不阻塞）。

## 宿主适配（屏幕 / 字号 / 深浅色）

原型的响应式只有 3 条，且**只有 1 条落在 markdown 范围**内：

| 原型响应式 | 处置 |
| --- | --- |
| `@media (max-width:1440px / 1024px){.sheet{padding:…}}` | **不适用**：`.sheet` 是样张页面架子的内边距，属宿主消息区，插件不写宿主规则 |
| `@media (max-width:768px){.md table{font-size:var(--text-xs)}}` | **已实现**（窄视口表格降字号）。局限要说清：这是**视口**口径，而插件宽度由宿主列宽决定（大屏 + 侧栏展开时列窄，视口断点判不到）—— 已由表格的 `overflow-x:auto` 横向滚动兜底 |
| 图片 `max-width:100%` / 表格 `overflow-x:auto` / 灯箱 `92vw`·`92vh` + 图 `max-height:86vh` | **已实现**，天然随窗口自适应 |
| **（本轮新增）容器查询** `@container (max-width:359px)`：极窄时缩放百分比值让位给图表 | **已实现**。为什么用容器查询而不是视口断点：插件可用宽度 = **消息列宽**（≠ 视口）—— 大屏 + 侧栏展开时列可能只有 380px，视口断点判不到；小窗口里列自然变窄，容器查询同样命中。**一条规则同管「大屏窄列」与「小屏」** |
| 工具条在窄列下的策略 | **收纳取代隐藏**：常驻从 8 个控件降到 4 个（视图切换 / 缩放分段 / 全屏浮窗 /「更多」），低频操作进菜单 —— 比「按宽度藏起来」更干净，且不依赖任何断点 |

**真正会「有的屏幕大、有的屏幕小」的维度不是屏幕尺寸，而是宿主的字号设置**：宿主有「设置 → 通用 → 外观 → 字号大小」（12–17，默认 14），通过 CSS 变量 `--dsh-content-font-size`（正文）、`--dsh-content-font-delta`（增量 = 设置值 − 14px）公开成**内容字号轴**。插件已接：

- 正文 / 表格 / `h4`：`var(--dsh-content-font-size,14px)`；
- `h1` / `h2` / `h3`：`calc(18px|16px|14px + var(--dsh-content-font-delta,0px))` —— **原型取值是「正文 14px」下的基线**，用增量平移即可在默认态**逐字对齐原型**、又在用户调字号时保持层级（宿主官方 markdown 也是这个写法，它的 h1 正好也是 `calc(21px + delta)`）；
- `h5` / `h6` / 小字档（`--mdr-fs-xs` 12px）**不缩放** —— 与宿主对 dense secondary text 的策略一致（缩到 11px 以下掉可读性）；
- 行高用相对倍数（1.6 / 1.4 / …）→ 随字号自动跟随，不需要 calc 补丁；行内代码 `.86em` 同理。

**刻意不跟随字号的**：几何（圆角 4/8/10/980）、间距（4/8/12/16/24）、动效时长、控件尺寸（26px 方格图标按钮 / 缩放分段 / 菜单）—— 原型给的是固定几何，字号缩放只作用于文字。

深浅色**不需要第二套取值**：颜色全由宿主语义变量取或派生，宿主深浅色开关（`body[data-ds-dark-theme]`）与系统偏好都自动跟随。

**对齐门禁**（防漂移）：

```bash
cd plugins/dsh-md-render && npx vitest run test/prototype-alignment.mjs
```

门禁把原型的每条 markdown 规则做成「选择器 → 声明块」断言（失败会点名**哪条规则缺哪个取值 + 原型出处**），并含 token 取值映射表、有意偏离清单、产物不漂移检查。**反向验证**：把任一条改回旧值（如 `h1` 竖条改回实心强调色）立刻红。
**独立核验记录（第二轮，fresh agent 逐条对照原型、不看实现者结论）**：核验 89 条原型规则 → 判定对齐 60 / 不符 6 / 不适用 19，另查出 4 类断言弱点（G1 漏测 h3·h5 字号与 6 条紧贴规则、G2 `@supports` 只查 at-rule 不查块体且 failed 态漏 `border-color`、G3 取规则块在 `@media` 内会撞重名选择器、G4 静态断言覆盖不到「声明在、行为死」）。**6 处不符已全部处置**：① 深色遮罩反相（高，改用宿主 `bg-mask-3`）；② 任务框死规则（中，删 `cursor` / `:focus-within` 并补只读行为断言）；③ 灰阶两档合并（低，登记为偏离 10）；④ 浮窗大图 `max-height` 取回 86vh（给关闭按钮留悬挑余量）；⑤ 文案 / 字重（低，登记为偏离 11）；⑥ 行内码底与发丝边的深色淡一档（低，改取宿主语义 token）。G1–G4 已补断言（`test/prototype-alignment.mjs` 的「核验补强」用例 + `test/own-markdown.mjs` 的只读行为），并对新增的关键断言做了反向验证（改回旧写法立刻红）。

**需真机核对（属用户本人人工走查范围，静态门禁覆盖不到）**：

1. 未勾选任务框描边用的 `label-tertiary` 对底色是否 ≥3:1（原型对应档位是 `--meta`，实测 3.62:1；宿主 tertiary 若更浅则改 `label-secondary`）；
2. 卡片头「**一行**」在极窄列下的观感（标题省略号截断的位置、缩放分段与「更多」的疏密）；
3. 深色态下自绘勾选框描边、表格行 hover、引用块薄底的实际可见度（这些仍走宿主语义色，静态门禁只能保证「取的是宿主 token」，观感要真机看）。

## 安装

```bash
dsh plugin --profile web add dsh-md-render --trust-lockfile
```

> 升级到本版本后**必须重启 `dsh web`**：host 半的资源白名单在启动时固定，老 host 会把两个新 assets URL 判成 404（此时插件真降级回官方形态，不报错）。

## 关键配置

设置 → 插件 → 渲染 页签可视化编辑，保存即生效、重启不丢；以下开关默认全部开启：`copyButton`（整段复制）、`textFenceMarkdown`（**围栏块渲染总开关**，关掉即全部交回宿主官方渲染）、`contextMarkdown`（上下文注入块渲染）。

> 原自实现渲染的开关（`syntaxHighlight` / `mathStructures` / `tableSort` / `codeTheme` 等 12 项）仍不存在（能力由自研渲染器提供，无开关）；patch 文件里的旧键保留无害。合并带来的包名 / 路由 / 配置键迁移见 [插件 README 的「破坏性变更与迁移」](../../plugins/dsh-md-render/README.md#破坏性变更与迁移)。

## 已知限制

- 围栏语言识别**不读 React fiber 私有属性**：DOM 契约（`code.language-*` / banner infostring）零请求优先；宿主 banner 只给本地化标签「代码块」时回落到 client 事件流索引与 host 半的有界语言索引（`GET /md-render/api/langs`，按块内容哈希，进程内、不落盘）；
- **全都拿不到语言**时仍按**代码视图**接管，但语言位留空（不写「代码块」、不猜语言、也不误判成 markdown）；想按 markdown 读就用块内「渲染为… → Markdown」；
- 解析层 / 高亮层懒加载：首屏到接管之间有「一次同源请求」的窗口（期间保持宿主官方形态）；加载失败按会话缓存、不再重试；
- 平台 `react-dom/client` 不可用时真降级：`MarkdownView` 落 `<pre>`，注入点保持宿主原样；
- 单块超长（markdown 围栏 > 10 万字符、代码块 > 20 万字符、上下文块 > 20 万字符）保持宿主原样；数学公式不做；raw HTML 永远是字面文本。

## 合并进来的能力（原 dsh-think-zh-expand / dsh-mermaid-render）

> 两个插件已下线（issue #463），能力并入本插件。以下保留「怎么跑 / 防复发 / 指针」，历史信息已删除。

### 思考块默认展开

- 实现：DOM 层对官方折叠行派发一次真实 click（外观 100% 官方），选择器 [data-variant="think"] [data-disclosure-row][aria-expanded]；WeakSet 一次性动作（幂等、尊重用户手动折叠）。
- 契约守卫 + 静默降级：选择器失配（宿主升级改属性）→ 退回官方默认，不报错、不写 DOM。
- 性能护栏：只在新增节点内定位 think 容器（先 matches 短路，再在容器内查行），单批最多 200 行。
- 开关：设置 → 插件 → 渲染 → 「思考块」分组（thinking.defaultExpanded）。
- 中文思考指令不在这里注入 —— 由 dsh-my-memory 的「全局提示词」提供。

### mermaid 图表卡片

- 引擎：assets/mermaid-10.9.3.min.js（3.34 MB）由 host 半静态托管于 /md-render/assets，client 首次渲染时 fetch 并按需注入 <script>；**不内联**进 bundle（issue #185 的 4.48 MB base64 冗余教训）。
- 渲染：离屏容器（.dsh-md-render-offscreen 类，脱离文档流但仍在布局树内）承接 mermaid 失败时的「炸弹图」，成功只取 svg 字符串。
- 流式：宿主在整条消息上挂 data-streaming，DOM 里看不到围栏是否闭合 → 用 400ms 稳定窗口 + 连续 2 次观察判定；源码再变即自愈卸载重来。
- 失败降级：卡片显示错误原因 + 重试 + **原始源码**（绝不静默丢内容）。
- 开关：设置 → 插件 → 渲染 → 「Mermaid 图表」分组（mermaid.render / mermaid.injectPrompt）。

### 排障

- 代码块没有高亮 / text 围栏没按 markdown 渲染：先看 Network 里 `/md-render/assets/marked-18.1.0.umd.js` 与 `/md-render/assets/highlightjs-11.12.0.min.js` 是不是 200 —— 404 说明 host 半是旧版本（资源白名单在启动时固定），**重启 `dsh web`** 即可；插件此时是真降级（块停在官方形态，不报错）。
- 代码块 banner 语言位是空的：说明该块的语言识别不出来（DOM 与两级索引都没答案）—— 属于设计内的「绝不编造语言名」，可用块内「渲染为…」手动指定。
- 卡片不出现：确认 mermaid.render 打开、块语言标记是 mermaid / mmd、会话滚动容器仍在（[data-conversation-scroll]）。
- 注入说明未生效：mermaid.injectPrompt 是否被显式设为 false。
