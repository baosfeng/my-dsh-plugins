# md 渲染（dsh-md-render）

> 源码：`plugins/dsh-md-render/` · [插件 README](../../plugins/dsh-md-render/README.md) · [文档索引](../索引.md)

## 功能

宿主官方 `MarkdownText`（GFM 表格 / 公式 / 代码块）覆盖了对话里的主流渲染路径；本插件**只做官方没覆盖的注入点与补位**，不再自实现任何 markdown 渲染：

- **text 围栏块渲染**：`text` / `plaintext` / `txt` 围栏块的内容交给官方渲染器按 markdown 渲染，每块带独立「查看原文」切换；
- **上下文注入块渲染**：宿主以纯文本 `pre[data-context-text]` 呈现的上下文注入正文（子 agent 回传消息 / AGENTS.md）交给官方渲染器渲染；
- **整段复制**：官方只有代码块复制，本插件补整段 markdown 复制按钮；
- **统一 MarkdownView**：`require('dsh-md-render').MarkdownView`（props `{ text }`）供本仓其他插件使用；
- **表格容错**：官方 GFM 不认的两种分隔行写法先规范化再交给官方渲染器。

## 安装

```bash
dsh plugin --profile web add dsh-md-render --trust-lockfile
```

## 关键配置

设置 → 插件 → 渲染 页签可视化编辑，保存即生效、重启不丢；以下开关默认全部开启：`copyButton`（整段复制）、`textFenceMarkdown`（text 围栏块渲染）、`contextMarkdown`（上下文注入块渲染）。

> 0.3.0 起，原自实现渲染的开关（`syntaxHighlight` / `mathStructures` / `tableSort` / `codeTheme` 等 12 项）已随实现下线，能力由官方内置；patch 文件里的旧键保留无害。迁移说明见 [插件 README](../../plugins/dsh-md-render/README.md#030-迁移说明开关下线)。

## 已知限制

- 围栏语言识别依赖官方 `CodeBlock` 的 React props（fiber），取不到则保持宿主原样（不报错）；
- 官方组件不可用时真降级：`MarkdownView` 落 `<pre>`，注入点保持宿主纯文本；
- 单块超长（text 围栏 > 10 万字符、上下文块 > 20 万字符）保持宿主原样。
