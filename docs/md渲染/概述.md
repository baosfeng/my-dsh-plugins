# md 渲染（dsh-md-render）

> 源码：`plugins/dsh-md-render/` · [插件 README](../../plugins/dsh-md-render/README.md) · [文档索引](../索引.md)

## 功能

非思考模式下模型输出的 Markdown 表格常以纯文本展示；本插件提供统一 MarkdownView 渲染层（表格 / 公式 / 代码块）与 DOM 层表格增强，并供 dsh-think-zh-expand 跨插件引用该渲染组件。

## 安装

```bash
dsh plugin --profile web add dsh-md-render --trust-lockfile
```

## 关键配置

设置 → 插件 → 渲染 页签可视化编辑，保存即生效、重启不丢；以下开关默认全部开启：`copyButton`（复制按钮）、`syntaxHighlight`（语法高亮）、`languageLabel`（语言标签）、`lineNumbers`（行号）、`taskList`（任务列表）、`strikethrough`（删除线）、`image`（图片）、`nestedList`（嵌套列表）、`mathStructures`（公式结构）、`tableSort`（表头排序）、`tableFold`（长表格折叠）。

## 主要能力

- **表格增强**：识别无首尾管道符、分隔行变体（`--- | ---`、`:---:`）等非标准写法，替换为带横向滚动的表格，逐列对齐并对单元格内联格式重渲染；已渲染表格不重复处理；
- **统一 MarkdownView**：零依赖轻量 LaTeX 子集渲染行内 `$...$` 与块级 `$$...$$`（分数 / 根号 / 上下标 / 求和积分 / 希腊字母），参数不完整时整个公式保持原文；
- **代码块**：容器附带语言标签与复制按钮，语法高亮覆盖 js / ts / python / json / bash / markdown / yaml，行号由 CSS counter 渲染、不污染代码文本（mermaid 扫描与复制结果不受影响）；
- **流式安全**：流式中的容器等内容稳定后再处理。
