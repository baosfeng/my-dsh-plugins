# dsh-md-render 重构契约（v1，冻结）

> 口径：**独立重构** —— 只参考功能与原型，不参考旧实现。旧代码仅用于确认「宿主契约不能变」。
> 规格真源：`docs/原型重构/dsh-md-render.html`（行号见侦察报告 §1）。
> 侦察报告：`/tmp/mdr-recon.md`（§1 规格 / §3 功能清单 / §5 边界 / §6 风险）。

## 一、必须沿用（否则宿主不认或门禁红）

| 项 | 约束 |
| --- | --- |
| 入口 | host `inject=['webServer','systemPrompt']` + `apply(ctx, config)`；client `exports.inject=[]` + `exports.apply` |
| 设置注册 | `settings.plugins.tab`：`id='md-render-settings'` / `order=90` / 惰性 label；`plugins.bundle.config`：`key='dsh-md-render'`（= package.json name）；slots 用 `ctx.get('slots', false)` |
| 配置 schema | `markdown.{copyButton,textFenceMarkdown,contextMarkdown}` / `thinking.defaultExpanded` / `mermaid.{injectPrompt,render}`，含旧扁平键兼容 |
| 路由 | `/md-render/api/config`、`/md-render/assets/*`、`/md-render/api/langs`（`src/routes/paths.ts` 单一真源） |
| 宿主 DOM 契约 | `div.md-code-block`、`pre[data-context-text="true"]`、`[data-variant="think"] [data-disclosure-row][aria-expanded]`、`[data-streaming]`、`[data-conversation-scroll]` |
| 解析层 | marked / hljs / mermaid / panzoom 一律 vendored 在 `assets/`，运行时 `<script>` 懒加载；**不进 bundle** |
| 公共 API | `MarkdownView({ text })` 保持 |
| 产物 | `lib/client.js` 与 `lib/*.js` 必须提交；写手不提交产物（集成窗口统一重建） |

## 二、命名（全部新建，不复用旧类名）

- 类名前缀 **`mdr-`**；数据属性 **`data-mdr-*`**；DOM 根作用域 **`.mdr-root`**。
- 状态用 `aria-*` + 语义类：`.is-active`、`.is-on`、`.is-copied`、`.is-collapsed`（**不用** `classList` / `cssText` / `el.style`，静态断言白名单只认 `setAttribute`）。

## 六、决策记录（leader 已拍板）

1. 工具栏按钮 **24×24**（原型 `.icon-btn`），替换旧的 26×26 方格。
2. 思考块：**接受宿主渲染**（折叠态内容不在 DOM，自绘不可行）；插件只负责默认展开 + 标题行文案/耗时 + 样式。
3. 设置页：自绘「渲染 / 关于」双 tab + 关于页；插件头部沿用宿主（不重复画）。
4. 「查看原文」：**整段级 + 围栏块级都做**（原型 3364 与 3389 各一处）。
5. mermaid 卡片头：标题取围栏块上下文里的真实标题，退化时用类型名；`.mm-kind` 显示 `flowchart` 等类型。

## 六（续）、集成窗口定型（2026-10-19）

1. **样式聚合**：`styles.ts` = `STYLES_BASE + STYLES_MARKDOWN + STYLES_CODE + STYLES_MERMAID + STYLES_SETTINGS`（5 个 part 有序拼接，注释头保留）。设置页样式**不再**由 `settings/index.ts` 二次注入（同一份 CSS 只进一次）；`installStyles` 调用点仍恰好 1 个，位于 `apply.ts` 最前。
2. **接线定型**：三路保留的兼容包装在集成窗口统一**删除**（不留死代码）——`CodeBlockView` / `CopyButton` / `MermaidCard` / `applyContextMarkdown`。调用面统一切到新导出：`markdown-view.ts` → `MdrCopyButton`（tip = 复制整段 markdown）、`scanner.ts` → 只用 `scanContextBlocks`（自身 + 后代）、`mermaid-scan.ts` → `MdrMermaidCard`。
3. **`applyThinkExpand`**：保留**可选参数** `root?: Element`（带参只扫该子树，无参回退全文档）；`scanner.ts` 的 `applyThinkExpand(el)` 保持不动——这是「按新增节点扫描」的既有契约，比无参全文档扫描更省。
4. **新增 part**：`own-markdown-blocks.ts`（A 路块级渲染从 414 行文件拆出，行为逐字不变），构建期排在 `own-markdown.js` 之后；锚点 `function mdTableNode(`。
5. **mermaid 失败态**：源码 `<pre class="mdr-mm-error-src">` 是 DOM 第一个节点（首屏即源码），失败原因降为一行灰字 + 重试按钮；视图分段的预览按钮由 `status === 'error'` 禁用。
6. **类名冲突修正**：markdown 卡底栏的三态容器类名由 `mdr-lang-switch` 改为 `mdr-block-switch`——前者是扫描器补注入控件的类，`scanLangSwitches` 会把同类节点当自己的清掉（会误删卡片底栏）。卡片挂载后主动 `removeLangSwitch(host)`，保证「一块一套入口」。

## 七、纪律（写手）

- 只写 write scope 内文件；不碰 `styles.ts`、`scripts/build.mjs`、`lib/**`、`apply.ts`、`src/index.ts`、`src/config.ts`、`src/routes/**`。
- 不跑整体 `node scripts/build.mjs` / `npm test`（共享工作树有他路中间态）；验收只跑自己新建的测试文件 + prettier。
- 解析层继续用 `render-assets.ts` 的懒加载入口，不自己加载脚本。
- 原型 JS 不能直接搬（它用 `classList`/`style`，违反静态断言白名单）；只搬视觉与状态语义。
- 每个交付含：源码 + 自己的测试文件（静态断言 + 纯函数单测）+ 证据命令。
