# Mermaid 渲染（dsh-mermaid-render）

> 源码：`plugins/dsh-mermaid-render/` · [插件 README](../../plugins/dsh-mermaid-render/README.md) · [文档索引](../索引.md)

## 功能

把对话里的 `mermaid` / `mmd` 代码块自动渲染成图表卡片（预览 / 代码切换）；mermaid 引擎随 client bundle 内联分发，零 CDN 依赖、离线可用。

## 安装

```bash
dsh plugin --profile web add dsh-mermaid-render --trust-lockfile
```

装完重启 `dsh web` 并硬刷新浏览器。

## 关键配置

| 配置键         | 作用                                                                                         |
| -------------- | -------------------------------------------------------------------------------------------- |
| `injectPrompt` | 是否向系统提示词注入 mermaid 能力说明，让模型知道可以主动画图（默认开，仅显式 `false` 关闭） |

也可在 **设置 → 插件 → Mermaid 渲染** 可视化编辑，保存写回 profile 的 `cordis.patch.yml` 并热生效；关闭只停止主动引导，已有代码块照常渲染。

## 主要能力

- 扫描代码块容器挂载 React 卡片，预览 / 代码两态切换，引擎按需加载；
- **闭合即渲染**：块内容稳定（约 400ms 内无变化）才挂载，非流式块零延迟；挂载后源码再变化则自愈卸载重等；
- **零炸弹图**：引擎在离屏容器内渲染后丢弃容器，解析失败只进卡片错误横幅（原因 + 源码 + 重试按钮），绝不出现引擎自插的错误图；
- 与 dsh-think-zh-expand 共用代码块容器，可共存。
