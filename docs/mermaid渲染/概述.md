# Mermaid 渲染（dsh-mermaid-render）

## 概述

DSH 对话 Mermaid 图表渲染插件（纯 client bundle）：把对话消息里的 `mermaid` / `mmd` 代码块自动渲染成**图表卡片**（预览 / 代码切换）。**mermaid 引擎在构建时内联进 client bundle（base64），零 CDN 依赖、完全离线可用**——规避了第三方插件依赖 jsdelivr CDN 在部分网络环境不可达导致图表空白的问题。

## 核心文件

| 文件路径                                            | 名称            | 说明                                                                                                 |
| --------------------------------------------------- | --------------- | ---------------------------------------------------------------------------------------------------- |
| `plugins/dsh-mermaid-render/lib/client.src.js`      | client 源码模板 | 扫描 `div.md-code-block` + `code.language-mermaid`，挂载 React 卡片；含 `__MERMAID_UMD_B64__` 占位符 |
| `plugins/dsh-mermaid-render/lib/client.js`          | client 构建产物 | `scripts/build.mjs` 注入 base64 引擎后生成（**必须提交**，CI 不构建）                                |
| `plugins/dsh-mermaid-render/scripts/build.mjs`      | 构建脚本        | 读 `vendor/mermaid.min.js` → base64 → 注入占位符 → 写 `lib/client.js`                                |
| `plugins/dsh-mermaid-render/vendor/mermaid.min.js`  | mermaid 引擎    | 3.3MB 自包含 UMD（含全部依赖）                                                                       |
| `plugins/dsh-mermaid-render/lib/index.js`           | server 端       | 空壳（纯 client 插件）                                                                               |
| `plugins/dsh-mermaid-render/test/client-render.mjs` | 渲染测试        | stub react + fake DOM 验证扫描/挂载/卡片结构                                                         |

## 业务场景映射

| 需求关键词             | 入口        | 关键路径                            | 文件路径            |
| ---------------------- | ----------- | ----------------------------------- | ------------------- |
| mermaid 代码块自动渲染 | client 扫描 | `installScanner` → `scan` → `mount` | `lib/client.src.js` |
| 引擎离线内联           | 构建        | `scripts/build.mjs`（base64 注入）  | `scripts/build.mjs` |
| 预览/代码切换          | 卡片组件    | `MermaidCard`（mode state）         | `lib/client.src.js` |
| 失败兜底               | 卡片组件    | `MermaidCard` error 分支            | `lib/client.src.js` |

## 使用方式

安装见 [安装与导入](../快速集成/安装与导入.md)（推荐 `dsh plugin --profile web add link:<仓库路径>/plugins/dsh-mermaid-render`；与 dsh-think-zh-expand 兼容共存）。装完后重启 `dsh web` 并硬刷新浏览器。
