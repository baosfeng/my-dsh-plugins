# 上下文透镜 + 成本治理（dsh-my-context）

> 源码：`plugins/dsh-my-context/` · [插件 README](../../plugins/dsh-my-context/README.md) · [文档索引](../索引.md)

## 功能

**上下文透镜**：统计每次请求的 token 用量与上下文构成，可视化 KV 缓存命中率，按会话隔离、重启恢复；**成本治理**：token 计量 + 每轮 / 每会话预算配置，超限提醒或拦截。

## 安装

```bash
dsh plugin --profile web add dsh-my-context --trust-lockfile
```

## 关键配置

- `perTurn` / `perSession`：每轮 / 每会话 token 上限（0 = 不限制）；
- `mode`：超限行为 `warn` 提醒（默认）或 `deny` 拦截并结束本轮；
- `warnThreshold` / `alertThreshold`：溢出预警与告警阈值。

预算也可在侧边栏面板中动态保存。

## 主要能力

- 计量取自会话事件流：请求头事件携带 system / tools 用于估算构成，助手消息携带真实的输入、输出与缓存读写用量；
- 上下文构成按 6 类展示占比，另显示累计 token、缓存命中率与模型路由；
- 预算检查在 agent 预步骤 waterfall 中执行，超限时告警透传或优雅结束本轮；
- 统计按会话分桶持久化（防抖 + 原子写 + 卸载前冲刷），启动异步加载不丢缓冲。
