# 上下文透镜 + 成本治理（dsh-my-context）

> 模块文档：`docs/上下文透镜/` — 源码：`plugins/dsh-my-context/`

**dsh-my-context** 是 DSH 上下文透镜 + 成本治理插件：**上下文透镜**（统计每次请求的 token 用量与上下文构成，KV 缓存命中率可视化，按会话隔离、重启后恢复）、**成本治理**（token 计量 + 每轮/每会话预算配置，超限提醒/拦截）。

## 业务场景映射

| 业务关键词                                           | 入口                                                                    | 说明                                                                                                                                                                                                                                                                                    |
| ---------------------------------------------------- | ----------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 上下文透镜 / token 用量 / 上下文构成 / KV 缓存命中率 | `plugins/dsh-my-context/lib/events.js` + `lib/meter.js`                 | 监听 `session/event`：`request/header`（system/tools 估算 + 模型路由）、`assistant/message`（真实 usage：input/output/cacheRead/cacheWrite）、`user/message`（user/inject 分类）、`tool/result`（tool 分类）；token 估算与 dsh token-meter 一致（~4 字符 ≈ 1 token + 4/block + 4/role） |
| 成本治理 / 预算控制 / 超限提醒 / 超限拦截            | `plugins/dsh-my-context/lib/budget.js` + `lib/events.js`                | 每轮/每会话 token 上限（0=不限制）+ warn/deny 模式；`agent/pre-step` waterfall 检查，超限时 warn 记录告警透传、deny 返回 `{ kind: 'reject' }` 结束本轮；`POST /context/api/budget` 动态更新配置                                                                                         |
| 统计持久化 / 重启恢复 / 会话隔离                     | `plugins/dsh-my-context/lib/store.js` + `lib/persist.js`                | 按 sessionId 分桶；持久化 `$DSH_HOME/context/context.json`（防抖 + 原子写 + teardown flush）；启动异步加载（缓冲不丢）；请求记录 500 条 / 告警 50 条上限                                                                                                                                |
| 上下文面板 / 预算设置                                | `plugins/dsh-my-context/lib/client.js`（`dsh-my-context:context` 页签） | 侧边栏面板：会话选择 + 概览卡片（累计 token/缓存命中率/模型）+ 构成条（6 分类占比）+ 请求记录列表 + 预算设置（每轮/每会话上限 + 模式 + 保存）+ 预算告警列表；可见时 5s 轮询、隐藏暂停                                                                                                   |
| 安全围栏                                             | `plugins/dsh-shared/lib/fence.js`                                       | 所有 API 请求 loopback 信任围栏（与 /api 网关一致契约）                                                                                                                                                                                                                                 |

## 调研结论（DSH 事件能力）

- **`llm/request` 事件不存在**（DSH 核心 dsh-llm / dsh-agent-loop / dsh-session 均无此事件）。token 计量改用 `session/event` 通道：`assistant/message` 事件携带真实 usage（disjoint 计数：`inputTokens` 已扣除 `cacheReadTokens`），`request/header` 携带 system prompt 与 tools（可估算构成），`request/context` 携带 contextWindow。
- **预算拦截点**：`agent/pre-step` waterfall（payload 含注入的 `agent`，`agent.id` = 会话 id），返回 `{ kind: 'reject' }` 优雅结束本轮（blocked），不破坏 agent 循环。
