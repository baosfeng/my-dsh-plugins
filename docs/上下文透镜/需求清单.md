## 易碎点

- **`llm/request` 事件不存在**（DSH 核心 dsh-llm / dsh-agent-loop / dsh-session 均无此事件）：token 计量走 `session/event` 的 `assistant/message`（data.usage 为 disjoint 计数：inputTokens 已扣除 cacheReadTokens），prompt 还原 = input + cacheRead + cacheWrite。
- **`agent/pre-step` waterfall 契约**：监听器必须先 `await next()` 拿到下游决策再决定是否覆盖；warn 模式一律原样返回下游决策；deny 拦截返回 `{ kind: 'reject' }`（PreStepDecision 类型，reject 不带 reason 字段）。绝不吞掉 next()。
- **持久化竞态**：store 异步加载期间的事件必须缓冲；卸载（dispose）时未就绪缓冲要回放；加载完成时不能覆盖本进程已产生的事件（mergeCurrent）。
- **构成语义**：system/tools 构成 = 当前请求头估算（覆盖式，每次请求都携带）；user/inject/assistant/tool 构成 = 会话消息累积（累加式）。
- **溢出预警口径**：用量比例 = **当前上下文长度**（`session.lastPromptTokens`：最近一次请求 prompt = input+cacheRead+cacheWrite，disjoint 还原；旧持久化数据回退最近请求快照的 prompt 字段）/ contextWindow。⚠️ 禁止用历史累计 usage（含每轮重复累加的 cacheRead，会把占用虚高到窗口的多倍——真实案例 1M 窗口显示 6718.8%）；contextWindow 未知（≤0）时不分级、不记录溢出事件；预警记录与预算告警分列（`overflows` / `alerts`）。
- **告警刷屏**：同一会话同一 scope 60s 冷却，防止每步超限时告警爆炸；溢出预警同样按同一会话同一级别 60s 冷却，且不阻塞步骤（只记录 + 面板展示）。
- **存储膨胀**：请求记录每会话 500 条、告警 50 条 FIFO 淘汰；溢出预警 50 条 FIFO 淘汰。
- **资源护栏参数一致性（issue #198）**：调度器 `PERSIST_MIN_INTERVAL_MS`（1s）必须 ≥ `atomicWriteJson` 的默认节流窗口（1s），否则护栏会拦下正常节奏（走重排路径，连续失败会放弃并丢状态）；`PERSIST_MAX_BYTES`（8MB）必须 ≥ 状态字节上界（会话数 × 单会话上限 + header）；参数集中在 `src/constants.ts`，改动需同步 `scripts/resource-smoke.mjs` 场景 5。**会话数上限 20（LRU）**命中会静默丢最久未使用的会话统计，改上限要同步评估内存/文件上界（20 × 单会话满载 132KB ≈ 2.6MB）。
