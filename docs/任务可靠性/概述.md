# 任务可靠性（dsh-task-reliability）

> 源码：`plugins/dsh-task-reliability/` · [插件 README](../../plugins/dsh-task-reliability/README.md) · [文档索引](../索引.md)

## 功能

保证长任务在六类中断场景下仍能跑完：模型超时/请求失败、任务提前结束、思考重复循环、进程重启、锁屏休眠后停滞、ask 长时间无响应；配套自主决策模式与远程触发接口。

## 安装

```bash
dsh plugin --profile web add dsh-task-reliability --trust-lockfile
```

## 关键配置

设置 → 插件 → 任务可靠性 页签可可视化编辑全部配置项，常用键：

| 配置键                                           | 作用                                                               |
| ------------------------------------------------ | ------------------------------------------------------------------ |
| `retryMax` / `retryBaseMs` / `retryableCodes`    | 请求级重试上限、指数退避基数、触发重试的错误码集合                 |
| `maxLoop` / `steerCooldownMs` / `rateMaxActions` | 自动继续次数上限、两次继续最小间隔、每分钟动作速率上限（防死循环） |
| `maxVerify`                                      | 每任务完成度校验次数上限                                           |
| `autopilot` / `autopilotGraceMs`                 | 自主决策默认开关与缓冲时长（缓冲超时后才自动决策，问题留待确认）   |
| `askTimeoutMs`                                   | ask 超时自动继续（毫秒，0 = 禁用）                                 |
| `watchdogIntervalMs` / `stallTimeoutMs`          | 任务停滞看门狗扫描间隔与停滞判定阈值                               |
| `rescueOnTruncation` / `rescueMaxPerSession`     | 输出截断自动补完开关与每会话次数上限                               |
| `apiToken`                                       | 远程触发接口鉴权                                                   |

## 主要能力

- **超时重试**：请求级自动重试，不产生用户可见消息、不消耗用户视角回合；
- **自动继续**：回合结束但任务未完成时注入继续指令；校验模式下由独立校验 agent 判断完成度，未完成则带结论唤醒主 agent；
- **思考重复干预**：流级相似度检测命中后终止回合，下一回合带分级打断指令；
- **重启与停滞恢复**：任务注册表持久化，启动时按幂等时间戳恢复会话；看门狗定期扫描停滞任务并唤醒（无需重启进程）；
- **ask 超时**：超时后模拟回答解锁回合，问题记录待用户确认；
- **多个入口**：侧边栏面板、HTTP API、`/task` 斜杠命令、远程触发接口。
