# 会话标题自动生成（dsh-session-title-gen）

> 源码：`plugins/dsh-session-title-gen/` · [插件 README](../../plugins/dsh-session-title-gen/README.md) · [文档索引](../索引.md)

## 功能

监听会话首条人类消息，用 LLM 生成类似 git commit 的结构化标题——先标明会话归属的工作区，再写简要描述，如 `[my-dsh-plugins] 修复记忆页签崩溃`，让会话列表一眼可辨归属与主题。

## 安装

```bash
dsh plugin --profile web add dsh-session-title-gen
```

## 关键配置

| 配置键                                                | 作用                                                          |
| ----------------------------------------------------- | ------------------------------------------------------------- |
| `enabled`                                             | 总开关，`false` 时不监听任何事件                              |
| `template`                                            | 标题模板，默认 `[{workspace}] {description}`                  |
| `provider` / `model`                                  | LLM 路由覆盖，缺省用会话请求路由                              |
| `maxTitleBytes` / `maxInputBytes` / `maxOutputTokens` | 标题字节上限（80）/ 送入 LLM 的消息字节上限 / 输出 token 上限 |
| `timeoutMs`                                           | LLM 调用超时，超时静默回退                                    |

## 设置页（可视化配置）

「设置 → 插件 → 会话标题生成」可视化编辑上表全部 8 项（不必手写 yml）：

- 保存 → `PUT /session-title-gen/api/config` → **先合并该行已有键**再写回 profile 的 `cordis.patch.yml`（不删用户手写的其它键，也不动其它插件行）→ 立即更新内存生效值并热切换监听（保存即生效，无需重启）；
- 非法值只回退该字段为默认值、不整单拒绝；保存后用响应回填**实际生效值**；
- 页签 id `session-title-gen-settings`（全局唯一，复用他人 id 会顶掉对方页签且不报错）；文案按宿主语言（`<html lang>` 优先，回退 `navigator.language`）返回**单语**，`label` 惰性求值；
- 实现：host 侧 `src/config.ts`（默认值 / 规整）+ `src/config-routes.ts`（HTTP 端点与路由注册，落**常驻 root**，webServer 晚就绪也补注册），client 侧 `src/client/`（`settings.plugins.tab` 席位 + `scripts/build.mjs` 占位符注入）。

## 排障

- 设置页提示「配置加载失败（404 / 服务端插件未加载）」：host 半未加载或 webServer 未就绪 —— 确认插件已安装启用后重启 DSH；
- 保存后标题未变：`enabled` 为关闭，或会话已有用户手动标题（`source: user`，本插件不覆盖）；
- 改 `template` 只影响**之后**生成的标题，已有标题不会重写。

## 主要能力

- 标题经核心 `session/title` 事件写入 append-only 会话日志，重启后自动保留，本插件不额外持久化；
- 工作区名由会话 cwd 向上找最近 `.git` 祖先取目录名；
- **失败回退**：LLM 不可用 / 超时 / 输出为空时静默跳过，核心标题机制照常工作，不阻塞会话；
- 用户手动重命名的标题不被覆盖；与核心标题生成器竞态时以去重后的结构化标题为准。
