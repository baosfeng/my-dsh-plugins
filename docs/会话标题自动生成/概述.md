# 会话标题自动生成（dsh-session-title-gen）

> 模块文档：`docs/会话标题自动生成/` — 源码：`plugins/dsh-session-title-gen/`

**dsh-session-title-gen** 是 DSH 会话标题自动生成插件（issue #160）：监听会话首条人类消息，用 LLM 生成类似 git commit 的**结构化标题**——先标明当前会话属于哪个（工作区/项目），再写一段简要描述，如 `[my-dsh-plugins] 修复 #143 记忆页签崩溃`。会话列表一眼可辨归属与主题。

## 业务场景映射

| 业务关键词                                      | 入口                                             | 说明                                                                                                                                                                                                                                                                                                                         |
| ----------------------------------------------- | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 结构化标题 / 会话标题 / 工作区归属 / git commit | `plugins/dsh-session-title-gen/lib/index.js`     | 监听 `session/event` 的 `user/message`（过滤插件注入）与 `session/title`（竞态兜底）；解析工作区名 → LLM 生成描述 → `session.append('session/title', ...)` 写入（log-backed，重启保留）                                                                                                                                      |
| 标题生成核心 / 模板格式化 / 流组装              | `plugins/dsh-session-title-gen/lib/title.js`     | 纯函数 + LLM 生成：`formatTitle`（模板 `{workspace}`/`{description}` 替换）、`isStructuredTitle`（方括号前缀启发式）、`collectStreamText`（轻量流组装，只收集 text-delta 与 finish，不依赖 `@deepseek-ai/dsh-llm` 的 BlockAssembler）、`foldTitle`（log 折叠）、`generateTitle`（`ctx.llm.stream` 调用 + 校验 + UTF-8 截断） |
| 工作区名解析                                    | `plugins/dsh-session-title-gen/lib/workspace.js` | 会话 cwd → `findProjectRoot`（dsh-shared，向上找最近 .git 祖先）→ basename 作为归属标识                                                                                                                                                                                                                                      |

## 与核心 dsh-session-title 的协作

| 机制         | 说明                                                                                                                                                                                                      |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 标题写入通路 | 核心 `session/title` 事件（log-backed，fold 取最后一个事件）；本插件直接 `session.append('session/title', ...)` 覆盖，不注册 provider（核心 bundle 已注册唯一 provider `session-title-first-prompt-llm`） |
| 竞态兜底     | 核心 fallback（user/message 后立即 defer）与核心 provider（request/header 后启动 LLM）都可能先于/后于本插件生成；监听 `session/title` 事件 + per-session 去重保证最终结构化标题生效且无循环               |
| 失败回退     | 生成失败（LLM 不可用/超时/输出为空/无路由）静默 catch，不 append，核心标题机制照常工作，不阻塞会话                                                                                                        |
| 尊重用户标题 | 用户手动重命名（source: user）不被覆盖                                                                                                                                                                    |
| 重启保留     | `session/title` 事件写入 append-only session log（持久化），重启后 fold 恢复标题，本插件不额外持久化                                                                                                      |

## 事件流

```
用户首条消息 ──► session/event (user/message, source.kind === 'user')
                    │
                    ▼
        解析工作区名（session.header.cwd → findProjectRoot → basename）
                    │
                    ▼
        LLM 生成描述（ctx.llm.stream，system 强制 [workspace] 格式，路由取会话请求或配置覆盖）
                    │
                    ▼
        session.append("session/title", { title, messageSeqs, source: { kind: "provider", provider: "dsh-session-title-gen", model } })
                    │
                    ▼
        会话列表（DSH 原生 + observability）显示结构化标题（重启保留）
```

核心生成的非结构化标题（fallback / provider）→ 触发 `session/title` 事件 → 本插件重新生成覆盖。

## 配置项

| 配置项            | 默认值                        | 说明                                             |
| ----------------- | ----------------------------- | ------------------------------------------------ |
| `enabled`         | `true`                        | 总开关（`false` 完全关闭，不监听任何事件）       |
| `template`        | `[{workspace}] {description}` | 格式模板（`{workspace}` / `{description}` 占位） |
| `provider`        | （缺省）                      | LLM provider 覆盖（缺省用会话请求路由）          |
| `model`           | （缺省）                      | LLM model 覆盖（缺省用会话请求路由）             |
| `maxTitleBytes`   | `80`                          | 标题 UTF-8 字节上限（与核心一致）                |
| `maxInputBytes`   | `4096`                        | 送入 LLM 的消息 JSON 字节上限                    |
| `maxOutputTokens` | `64`                          | LLM 输出 token 上限                              |
| `timeoutMs`       | `30000`                       | LLM 调用超时（超时静默回退）                     |
