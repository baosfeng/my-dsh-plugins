# 共享工具包（dsh-shared）

> 源码：`plugins/dsh-shared/` · [插件 README](../../plugins/dsh-shared/README.md) · [插件资源安全规范](../开发指南/插件资源安全规范.md) · [文档索引](../索引.md)

## 功能

仓库的 server 端共享工具包：把多插件间复制粘贴的公共实现收敛为单一来源，并把资源护栏统一收口——默认安全（不传参也有护栏）、内存有界、写入可调度、超限自动降级。

## 安装

本包是库而非 DSH 插件，不单独安装：依赖方在自己的 `dependencies` 中声明 `dsh-shared`，随插件安装自动装入（跨插件依赖需先发版）。

## 原语清单

| 原语              | 作用                                                                     |
| ----------------- | ------------------------------------------------------------------------ |
| 信任围栏          | Host-header 校验（回环 / 可信 host / 同源），供各插件 API 路由复用       |
| HTTP JSON 读写    | 请求体解析与 JSON / 错误响应输出                                         |
| 配置持久化        | 读写 profile 的 patch 配置块（YAML 子集）                                |
| 项目根解析        | 从 cwd 向上找最近 `.git` 祖先                                            |
| 原子写快照        | tmp + rename 落盘，默认 1s 节流 + 1MB 上限，被拦一律告警计数、不静默跳过 |
| JSON Lines 追加器 | 高频事件增量追加 + 阈值 compact，避免写放大                              |
| 有界容器          | LRU / FIFO 上限 + 淘汰计数 + 淘汰回调                                    |
| 写入调度器        | 防抖 + 最小间隔 + 串行链，提供确定性就绪信号与退出前强写                 |
| 降级看门狗        | 采样到阈值判定再到连续确认后降级 / 恢复，带历史与统计，时钟可注入        |

## 选用要点（先读再选）

- **持久化三选一**：事件流用 JSON Lines 追加器（每条事件全量重写会造成数百倍写放大）；状态快照用写入调度器 + 原子写；配置或用户显式保存用原子写并加 `force`，否则连续保存会被节流窗口吞掉；
- **内存有界**：字典 / 表要有上界就用有界容器，需要「最近 N 条明细」用 FIFO 列表；淘汰是静默丢数据语义，上限必须显式；
- **写入节奏只能有一个来源**：用写入调度器时内部快照原语的节流必须置 0，两道节流叠加会让状态永不落盘且只留一条告警；
- **降级必须有动作**：只告警不动作等于等人手动介入；降级期间内存同样要保持有界，恢复后补一次全量快照。
