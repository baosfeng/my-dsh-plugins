## 场景（右下角「场景」胶囊）

1. **侧边栏文件活动**（默认）：右侧栏「文件活动」tab 激活，展示最近访问 + 文件统计树。
2. **浮窗预览**：点击文件后的浮窗，内含代码 / Markdown / 图片 / PDF / 沙箱 HTML 多态切换。
3. **设置·文件活动**：设置弹层 → 插件 → 文件活动，自动打开开关 + 默认宽度滑块。
4. **空态 / 降级**：新会话无记录的空态；扩展点注册失败时的降级提示。

## 必须覆盖（验收逐条核对）

### 右侧栏
- [ ] F1 tab 头：`文件` / `文件活动`（激活）/ `+`；tab 右侧有面板开关图标。
- [ ] F2 最近访问：折叠头（chevron + 「最近访问」+ 刷新/清空图标按钮）、最多 5 条、同文件去重、行 = 操作徽标（读取/新增/修改，三色）+ 文件名 + 相对时间（刚刚 / 3 分钟前 / 昨天）。
- [ ] F3 文件统计：树形目录，目录行粗体 + chevron，单链压缩为 `docs.原型重构`，文件和目录右侧显示 `读取 3 / 新增 1 / 修改 2` 计数与相对时间；悬停显示完整时钟时间（tooltip）。
- [ ] F4 刷新 / 清空按钮：清空需二次确认（内联确认条或弹层）。
- [ ] F5 空态：两行「暂无文件活动」+「agent 读写文件后会自动出现在这里」。
- [ ] F6 降级态：错误/不可用提示条。

### 浮窗预览
- [ ] F7 浮窗：标题 = 文件名 + 路径 + 关闭 ×；点击窗外 / Esc 关闭；长内容内滚动。
- [ ] F8 多态：代码（高亮 + 行号）、Markdown（标题/列表/代码）、图片、PDF（工具栏示意）、沙箱 HTML（预览 + 源码切换）。

### 设置
- [ ] F9「会话开始时自动打开」开关。
- [ ] F10「右侧边栏默认宽度」滑块 10%–70%（默认 20%），带当前值。
