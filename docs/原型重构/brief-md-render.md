# 原型 brief · dsh-md-render

> 前置：[设计基线](设计基线.md)。产物：`docs/原型重构/dsh-md-render.html`（单文件自包含）。
> 先读 plugins/dsh-md-render/README.md、docs/md渲染/概述.md，以及 src/client/settings/view.ts、parts/own-code.ts、own-markdown.ts、mermaid-card.ts、mermaid-toolbar.ts、lang-switch.ts、think.ts、copy.ts。

## 场景（右下角「场景」胶囊）

1. **对话渲染**（默认）：一条完整 AI 回答，覆盖全部围栏块与 markdown 元素。
2. **mermaid 全屏浮窗**：图表卡片点「全屏」后的 `<dialog>` 浮窗（90vw×85vh + 遮罩 + 缩放条 + Esc 关闭）。
3. **设置·渲染**：设置弹层 → 插件 → 渲染 tab，三分组开关。
4. **空态与降级**：无消息 / 解析层未就绪时块保持官方形态的降级提示。

## 必须覆盖（验收逐条核对）

### 对话区
- [ ] F1 思考块：默认展开，标题行「思考中 / 已思考」，可手动折叠。
- [ ] F2 markdown 围栏块：标题 h1–h3、段落、有序/无序列表、任务列表（只读勾选，含 `- [x]` 与未勾选）、表格（圆角外框、表头薄底、行 hover）、引用块（左竖线 + 淡底）、分隔线、行内代码、链接、图片；块内「查看原文」。
- [ ] F3 代码块（JS / JSON / BASH 各一）：语言胶囊（大写真实语言名）、行号可选、复制按钮（默认隐形，hover/focus 浮现）、换行切换按钮、长行横向滚动、highlight 高亮。
- [ ] F4 无语言围栏块：代码视图 + 语言位留空（不写「代码块」）。
- [ ] F5「渲染为…」三态切换：块内控件「图表 / Markdown / 源码」，三态可见、有选中态。
- [ ] F6 mermaid 图表卡片：卡片头标题胶囊 + 工具条（预览/代码切换、缩放分段 − 100% +、全屏、更多菜单）；内容区流程 SVG；「更多」菜单含导出 PNG / 导出 SVG / 缩放模式（适应容器 / 适应宽度）/ 复制代码。
- [ ] F7 整段复制：MarkdownView 容器右上角图标按钮（hover 浮层「复制整段 markdown」）。
- [ ] F8 上下文注入块：子 agent 回传消息样式，按 markdown 渲染，标注「上下文注入」。
- [ ] F9 流式态示意：一条消息带 streaming 光标 / 骨架（可选场景内展示）。

### 设置·渲染
- [ ] F10 三组开关：Markdown（复制按钮 / 围栏块渲染总开关 / 上下文注入块）、思考块（默认展开）、Mermaid 图表（注入能力说明 / 渲染为图表卡片）。
- [ ] F11 保存反馈（已保存 toast）、配置说明文字。

## 文案与数据
- 使用中文界面；代码块语言 `JS` / `JSON` / `BASH`；按钮「复制」「已复制」「查看原文」「渲染为…」「预览」「代码」「更多」「全屏」「导出 PNG」「导出 SVG」。
- 示例对话内容要真实：写一段关于「实现一个带重试的 HTTP 客户端」的回答，含代码、表格、任务列表、mermaid 流程图、思考块。
