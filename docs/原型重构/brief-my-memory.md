# 原型 brief · dsh-my-memory

> 前置：[设计基线](设计基线.md)。产物：`docs/原型重构/dsh-my-memory.html`（单文件自包含）。
> 先读 plugins/dsh-my-memory/README.md、docs/记忆/概述.md，以及 src/client/parts/view.ts、view-rows.ts、prompts.ts、candidates.ts、confirm-ui.ts、styles.ts；字段语义看 src/memory-types.ts、memory-scoring.ts。

## 场景（右下角「场景」胶囊）

1. **设置·记忆**（默认）：全局记忆 + 项目记忆两个分区，含条目详情、输入新增。
2. **确认态**：保存确认（绿色）/ 删除二次确认（红色）/ 编辑态。
3. **候选待确认**：自动学习候选列表（确认写入 / 拒弃）。
4. **设置·全局提示词**：提示词列表（含内置种子「中文思考」）、启停、排序、编辑/删除。
5. **空态与异常**：全部为空、超长精简提示、加载失败。

## 必须覆盖（验收逐条核对）

### 记忆分区
- [ ] F1 分区头：`全局记忆`（全局徽标 + 说明「注入系统提示词，agent 始终携带」+ 存储位置）+ `项目记忆`（accent 边框 + 项目根徽标 + 说明）。
- [ ] F2 条目行：首句概要（单行省略）+ 分类徽标（偏好/事实/项目/技术栈/工作流）+ 置信度（★ 4/5 或进度条）+ 更新时间；点击展开详情（完整描述、来源会话、演进历史、矛盾警示「待处理矛盾」）。
- [ ] F3 条目操作：编辑（内联）、删除（danger，二次确认）。
- [ ] F4 新增输入：输入框 + 「新增」按钮；超长提示「建议不超过 50 字，当前 72 字」。
- [ ] F5 保存 / 删除确认 UI：自定义确认层（保存绿色、删除红色二次确认）；说明「所有新增 / 修改 / 删除都需要你确认」。
- [ ] F6 候选待确认：标题「自动学习候选（待确认）」+ 条目（来源会话、时间、置信度）+ 「确认写入」「拒弃」。

### 全局提示词
- [ ] F7 分区头：`全局提示词` + 说明「必须始终生效的指令，每轮全量按序注入，不参与记忆检索」+ 与记忆隔离的提示。
- [ ] F8 提示词条目：标题、正文摘要、启用开关、上移/下移、编辑、删除；内置种子标注「内置」。
- [ ] F9 新增提示词：标题 + 正文 textarea + 字数（上限 1000）+ 保存。
- [ ] F10 停用态样式（条目变淡 + 「已停用」徽标）；排序顺序可视化。

## 文案与数据
- 示例：全局 3 条（含 1 条矛盾警示、1 条展开详情），项目 2 条，候选 2 条，提示词 3 条（含内置「中文思考」）。
- 按钮文案：新增、编辑、删除、保存、取消、确认删除、确认写入、拒弃、上移、下移、启用、停用。
