# 原型重构 · 设计基线

> 四份插件原型（dsh-md-render / dsh-file-activity / dsh-my-memory / dsh-my-notify）共用的视觉与结构基线。
> 每份原型是**单文件自包含 HTML**，模拟 DSH Web GUI 外壳，覆盖该插件全部功能与状态。

## 一、交付物

| 文件 | 插件 | 覆盖 |
| --- | --- | --- |
| `dsh-md-render.html` | dsh-md-render | 对话内围栏块接管、代码块、mermaid 卡片、渲染为…、复制、思考块、上下文注入块、设置面板 |
| `dsh-file-activity.html` | dsh-file-activity | 右侧栏文件活动页签、最近访问、文件统计树、浮窗预览多态、设置面板、空态/降级态 |
| `dsh-my-memory.html` | dsh-my-memory | 设置·记忆分区、全局/项目、条目详情、新增/编辑/删除确认、候选待确认、设置·全局提示词 |
| `dsh-my-notify.html` | dsh-my-notify | 设置·通知提醒、四类触发开关、出站 Webhook 列表与编辑、toast/系统通知/权限态、远程触发 |

每份原型打开即是一个可交互的 DSH 窗口，右下角「场景」胶囊切换该插件的关键场景，右上角切换深浅主题。

## 二、画布与外壳

- 画布 1440×900（`@media` 断点 1440 / 1024 / 768，768 以下不保证）。
- 窗口 = 左侧栏 260px + 主区（自适应）+ 可选右侧栏 380px；三者都是圆角 12px 的独立面板，间距 8px，底色 `--bg`。
- 左侧栏：`deepseek HARNESS` 标识、新建会话按钮、Workspaces（当前工作区高亮）、会话列表（标题 + 相对时间 + 状态点）、底部设置入口。
- 顶栏 48px：会话标题 + 模型名 + 右侧栏开关图标 + 更多菜单。
- 主区：对话消息列最大 760px 居中；或设置页内容、插件面板内容。
- 右侧栏：tab 头（`文件` / `文件活动` / `+`）+ 面板内容；默认展示文件活动。
- 设置页：居中弹层 1120×740，左侧 220px 分类导航（通用设置 / 模型 / 模型调用供应商 / 插件 / Agent 预设 / Token 用量 / 视觉工具 / 插件市场 / 侧边卡片），右侧内容区；顶部标题「设置」+ 关闭按钮；插件分类下用二级 tab 呈现本插件页签。

## 三、主题与 token

深浅两套，默认深色；`<html data-theme="dark|light">` 切换，跟随 `prefers-color-scheme` 初值。全部颜色只从变量取，不写裸色值。

```css
:root[data-theme="dark"]{
  --bg:#151517; --bg-elevated:#232324; --bg-hover:#2c2c2e; --surface:#2c2c2e;
  --surface-raised:#353638; --border:rgba(255,255,255,.12); --border-soft:rgba(255,255,255,.06);
  --text:#f9fafb; --text-2:#cfd3d6; --text-3:#adb2b8;
  --accent:#5686fe; --accent-hover:#7aaaff; --accent-soft:rgba(86,134,254,.16); --on-accent:#ffffff;
  --success:#22c55e; --success-soft:rgba(34,197,94,.14);
  --warn:#f59e0b; --warn-soft:rgba(245,158,11,.14);
  --danger:#f25a5a; --danger-soft:rgba(242,90,90,.15);
  --code-bg:#1b1b1c; --toast-bg:#2c2c2e; --overlay:rgba(0,0,0,.5);
  --shadow:0 8px 24px rgba(0,0,0,.18);
}
:root[data-theme="light"]{
  --bg:#ffffff; --bg-elevated:#f5f6f7; --bg-hover:rgba(38,49,72,.06); --surface:#ffffff;
  --surface-raised:#f9fafb; --border:rgba(0,0,0,.10); --border-soft:rgba(0,0,0,.04);
  --text:#0f1115; --text-2:#61666b; --text-3:#81858c;
  --accent:#4176e6; --accent-hover:#4868b2; --accent-soft:rgba(65,118,230,.10); --on-accent:#ffffff;
  --success:#22c55e; --success-soft:rgba(34,197,94,.10);
  --warn:#f59e0b; --warn-soft:rgba(245,158,11,.10);
  --danger:#ec1313; --danger-soft:rgba(236,19,19,.08);
  --code-bg:#f9fafb; --toast-bg:#ffffff; --overlay:rgba(0,0,0,.24);
  --shadow:0 8px 24px rgba(0,0,0,.10);
}
```

**取值出处（对齐 DSH 宿主，不自行发明颜色）**：所有颜色取自 DSH Web 前端内置设计系统（`@deepseek-ai/dsh-web-frontend` 产物里的 `--dsw-static-*` / `--dsw-alias-*`）。逐项对照：

| 原型 token | 深色 | 浅色 | DSH 出处 |
| --- | --- | --- | --- |
| `--bg` | `#151517` | `#ffffff` | `neutral-bluish-950` / `-00` |
| `--bg-elevated` | `#232324` | `#f5f6f7` | 派生值 / `neutral-bluish-60` |
| `--surface` / `--bg-hover` | `#2c2c2e` | `#ffffff` / `rgba(38,49,72,.06)` | `neutral-bluish-850` / `-00` |
| `--surface-raised` | `#353638` | `#f9fafb` | `neutral-bluish-800` / `-50` |
| `--border` / `--border-soft` | `rgba(255,255,255,.12 / .06)` | `rgba(0,0,0,.10 / .04)` | `alias-border-l3` / `alias-border-l1` |
| `--text` / `-2` / `-3` | `#f9fafb` / `#cfd3d6` / `#adb2b8` | `#0f1115` / `#61666b` / `#81858c` | `label-primary/secondary/tertiary`（`neutral-bluish-1000/700/600`） |
| `--accent` | `#5686fe` | `#4176e6` | `alias-brand-primary-new-color` = `deepseek-450` / `deepseek-500` |
| `--accent-hover` | `#7aaaff` | `#4868b2` | `deepseek-400` / `deepseek-600` |
| `--success` | `#22c55e` | `#22c55e` | `static-green-500` |
| `--warn` | `#f59e0b` | `#f59e0b` | `static-amber-500` |
| `--danger` | `#f25a5a` | `#ec1313` | `static-red-400` / `static-red-600` |
| `--code-bg` | `#1b1b1c` | `#f9fafb` | `neutral-bluish-900` / `alias-markdown-code-block` |
| `--on-accent` | `#ffffff` | `#ffffff` | `alias-label-primary-foreground` |

深色主色取 `deepseek-450`（`#5686fe`）而非信息按钮的 `deepseek-400`，是因为宿主品牌主色新色在深色下就是 450、浅色下是 500；`#4176e6` 同时充当浅色主色。

几何与排版（固定）：圆角 4 / 6 / 8 / 10（徽标与标签 4、控件 6、卡片与面板 8、窗口与弹层 10，即宿主 4/8/12/16 体系里的紧凑档）；正文 14px/1.6、次级 12px/1.5、标题 21/17/15/14/13/12；间距 4/8/12/16/24；控件高 26px（图标按钮 26×26 方格）、行高 28–32px；字体栈 `-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif`，等宽 `ui-monospace, "SF Mono", Menlo, Consolas, monospace`；阴影取 `--shadow`（深色 `.18` / 浅色 `.10`）；焦点环 `0 0 0 3px var(--accent-soft)`。

## 四、组件规范

- **按钮**：主按钮 = accent 底 + 白字；次按钮 = 透明底 + `--border` 描边；危险 = danger 底或 danger 文字；图标按钮 26×26 方格 + hover 浮层文字（`data-tip` 属性，`::after` 绝对定位，不撑开布局）；所有按钮有 hover / active / focus-visible / disabled 态。
- **开关**：`<button role="switch" aria-checked>`，44×26 胶囊，开 = accent，关 = `--surface-raised`，150ms 过渡。
- **输入**：高 32px，圆角 8，`--bg-elevated` 底 + `--border` 描边，focus 时 accent 边框 + 光晕。
- **徽标**：分类/状态徽标 11–12px，色彩取语义软底（`--success-soft` 等）+ 对应文字色；文件类型徽章用色块 + 短标记。
- **卡片**：圆角 12，`--surface` 底 + `--border` 描边；区块头 = 标题 + 操作按钮组。
- **列表行**：高 28–32px，hover `--bg-hover`；左侧图标/徽标，中间名称（省略号），右侧 meta（相对时间/计数）。
- **树**：目录行粗体 + accent 色，文件行常规；chevron 指示展开；单链目录压缩 `a.b.c`。
- **文件类型图标**：对齐宿主文件树，用彩色类型图标（TS 蓝 `#3178c6`、JS 黄 `#f0db4f`、MD 蓝 `#519aba`、HTML 橙 `#e37933`、TOML 红 `#cf222e`、`package.json` 绿六边形、JSON 黄色花括号、文件夹与通用文件中性灰 `#8b96a3`），不用单色线条图标区分类型。
- **文件活动语义**：读取 / 新增 / 修改用无底色小字（10.5px，accent / success / warn 三色）跟在文件名后，统计计数同样去底色、只保留颜色区分；不用彩色胶囊，避免整列色块压过文件本身。
- **tab**：右侧栏 tab 头 36px，激活项 accent 下划线；设置二级 tab 用分段胶囊。
- **toast**：右下角 360px 卡片，类型标签（Notice / 询问 / 审批）+ 标题 + 摘要 + 时间，点击抬升。
- **对话框**：遮罩 `--overlay` + 居中卡片；确认类对话必须有取消/确认两按钮，删除用 danger。
- **代码块**：`--code-bg` 底，语言胶囊（accent 软底 + accent 文字，大写），复制按钮，长行横向滚动。
- **mermaid 卡片**：卡片头 = 标题 + 工具条（预览/代码、缩放 − 100% +、全屏、更多），内容区 SVG 示例。
- **markdown 内容**：标题阶梯、列表、任务框（只读勾选）、表格、引用块、行内代码、链接、图片。

## 五、状态与动效

- 每个可交互元素都必须有 hover、active、focus-visible；禁用 `opacity:.4`；loading 用占位或「加载中…」；空态 = 主文案 + 次级 hint 两行；错误态 = danger 文字 + 重试入口。
- 动效只用 `transform` / `opacity`：hover 150ms、进入 220ms、`cubic-bezier(.28,0,.22,1)`；`prefers-reduced-motion` 下全部关闭。
- 图标一律内联 SVG（stroke 1.8，viewBox 24），不用字体图标和外部依赖。

## 六、原型工具（每个页面必备）

- 右下角「场景」胶囊：横向滚动按钮组，切换该插件的关键场景（见各插件 brief）；切换时主区淡入 220ms。
- 右上角主题切换按钮（太阳/月亮图标）。
- 页面顶部不加大标题、不写说明文字——原型本身就是界面；说明放各插件 README。

## 七、约束

- 单文件、零外部依赖（无 CDN、无图片外链；示意图片用内联 SVG data URI）。
- 所有文案简体中文；数据是示例数据，贴近真实（路径、会话标题、时间）。
- 不实现真实后端；按钮点击给前端反馈即可（toast / 状态变化 / 弹层）。
- 每个功能点都必须能在页面上被看到或点开；验收按插件 README 的功能清单逐条核对。
