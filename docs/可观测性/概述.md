# 可观测性 + Git 工程工具（dsh-my-observability）

> 源码：`plugins/dsh-my-observability/` · [插件 README](../../plugins/dsh-my-observability/README.md) · [文档索引](../索引.md)

## 功能

记录 agent 行为并提供工具面增量：**事件审计**（监听状态、模型流、工具调用事件，按会话隔离、重启恢复、跨会话经 API 查询）、**资源监控面板**（审计写入速率 + 进程资源）、**结构化 Git 提交**（Conventional Commits）、**增量 diff 审查**（提交前规则引擎 + 可选 AI 审查）。

## 与官方 Trajectory 的分工

可视化轨迹回放**不再由本插件提供**：官方 UI 插件 `@deepseek-ai/dsh-client-ui-trajectory`（DSH 0.1.7-rc.2 起默认装载）已提供对话视图环里的 Trajectory 页签——按轮次的事件记录表、交互式时间概览与记录检查器（token 用量 / 耗时 / 输入输出）。本插件保留的增量是官方没有的部分：

- 跨会话、跨重启的审计落盘（`$DSH_HOME/observability/audit.jsonl`）与查询 API（官方 Trajectory 只投影当前会话的驻留窗口）；
- 结构化 Git 工具（类型化提交 / 状态 / 差异）；
- 提交前增量 diff 规则审查（密钥、调试残留等）；
- 资源看门狗（写放大自动降级落盘 + 面板可视）。

## 安装

```bash
dsh plugin --profile web add dsh-my-observability --trust-lockfile
```

## 关键配置

| 配置键        | 作用                                                          |
| ------------- | ------------------------------------------------------------- |
| `aiReview`    | 增量 diff 审查启用 AI 增强（默认开；agents 服务不可用时降级） |
| `aiTimeoutMs` | AI 审查超时毫秒（默认 60000，非法 / 非正数回退默认）          |

上表两项可在 **设置 → 插件 → 可观测性** 可视化编辑，保存写回 profile 的 `cordis.patch.yml` 并热生效；其余字段（`aiProvider` / `aiModel` / `aiCwd` / `resourceIntervalMs`）仍写在 `cordis.patch.yml`。

## 主要能力

- **事件审计**：监听 agent 状态、LLM 流、工具调用与结果事件，全部只读观察、waterfall 透传；
- **持久化**：按会话分桶，以 JSON Lines 增量追加 + 防抖批量 flush + 周期原子快照，落盘字节约为事件本体字节；每会话 2000 条 / 全局 20000 条上限；
- **查询 API**：`/observability/api/sessions`、`/events?sessionId=&type=&limit=`（`sessionId=*` 跨会话）、`/status`、`/errors`、`/plugin-status`、`/resources`；
- **资源监控页签**：审计文件大小/写入速率 + CPU/内存 + 告警列表；连续超限自动停落盘、回落自动恢复（`degraded` 标记）；
- **结构化 Git**：按类型 / 范围 / 描述拼出 Conventional Commits 提交信息并执行 add + commit，另提供状态与 diff 查询；
- **提交前审查**：解析 unified diff 后跑规则引擎（调试残留、密钥、冲突标记、TODO、尾随空格、大 diff、二进制、无测试变更），可选接 AI 审查且在失败时降级；
- 所有 API 请求走 loopback 信任围栏。
