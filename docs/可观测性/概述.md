# 可观测性 + Git 工程工具（dsh-my-observability）

> 源码：`plugins/dsh-my-observability/` · [插件 README](../../plugins/dsh-my-observability/README.md) · [文档索引](../索引.md)

## 功能

记录 agent 行为并提供可视化回放：**事件审计**（监听状态、模型流、工具调用事件，按会话隔离、重启恢复）、**轨迹回放面板**（侧边栏时间轴）、**结构化 Git 提交**（Conventional Commits）、**增量 diff 审查**（提交前规则引擎 + 可选 AI 审查）。无插件级配置项。

## 安装

```bash
dsh plugin --profile web add dsh-my-observability --trust-lockfile
```

## 主要能力

- **事件审计**：监听 agent 状态、LLM 流、工具调用与结果事件，全部只读观察、waterfall 透传；
- **持久化**：按会话分桶，以 JSON Lines 增量追加 + 防抖批量 flush + 周期原子快照，落盘字节约为事件本体字节；每会话 2000 条 / 全局 20000 条上限；
- **轨迹回放**：侧边栏时间轴，支持会话选择与事件类型过滤，展示徽标、时间与摘要；
- **结构化 Git**：按类型 / 范围 / 描述拼出 Conventional Commits 提交信息并执行 add + commit，另提供状态与 diff 查询；
- **提交前审查**：解析 unified diff 后跑规则引擎（调试残留、密钥、冲突标记、TODO、尾随空格、大 diff、二进制、无测试变更），可选接 AI 审查且在失败时降级；
- 所有 API 请求走 loopback 信任围栏。
