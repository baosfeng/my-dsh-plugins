# 可观测性 + Git 工程工具（dsh-my-observability）

> 模块文档：`docs/可观测性/` — 源码：`plugins/dsh-my-observability/`

**dsh-my-observability** 是 DSH 可观测性 + Git 工程工具插件：**事件审计**（监听 agent/status、llm/stream、tools/* 事件，记录 agent 行为，按会话隔离、重启后恢复）、**轨迹回放面板**（侧边栏时间轴查看 agent 行为）、**结构化 Git 工具**（Conventional Commits 类型化提交）、**增量 diff 审查**（提交前规则引擎 + 可选 AI 审查）。

## 业务场景映射

| 业务关键词                                     | 入口                                                                               | 说明                                                                                                                                                                                                                                                                           |
| ---------------------------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 事件审计 / agent 行为记录 / 可追溯             | `plugins/dsh-my-observability/lib/audit.js`                                        | 监听 `agent/status`（agent_status）、`llm/stream`（llm_stream，同步包装流透传）、`tools/pre-execute`（tool_call）、`tools/execute`（tool_result），全部只读观察、waterfall 透传 next()                                                                                         |
| 审计持久化 / 重启恢复 / 会话隔离               | `plugins/dsh-my-observability/lib/store.js` + `lib/store-persist.js`               | 按 sessionId 分桶；持久化 `$DSH_HOME/observability/audit.jsonl`（**增量追加** jsonl + 防抖批量 flush + 周期 compact 原子快照 + teardown flush，落盘字节 ≈ 事件本体字节，无写放大）；启动异步加载（缓冲不丢）；每会话 2000 条 / 全局 20000 条上限；旧格式 `audit.json` 自动迁移 |
| 轨迹回放 / 时间轴 / 会话轨迹                   | `plugins/dsh-my-observability/lib/client.js`（`dsh-my-observability:replay` 页签） | 侧边栏时间轴：会话选择 + 类型过滤（状态/模型流/工具）+ 事件徽标/时间/摘要；可见时 5s 轮询、隐藏暂停                                                                                                                                                                            |
| 结构化 Git / 类型化提交 / Conventional Commits | `plugins/dsh-my-observability/lib/git.js`                                          | `POST /observability/api/git/commit`（type/scope/description/body → `<type>(<scope>): <desc>`，execFile 执行 git add + commit）；`GET /git/status`、`GET /git/diff`                                                                                                            |
| 增量 diff 审查 / 提交前审查                    | `plugins/dsh-my-observability/lib/review.js` + `lib/ai.js`                         | `POST /observability/api/review`：unified diff 解析（lib/diff.js）+ 8 条规则引擎（调试残留/密钥/冲突标记/TODO/尾随空格/大 diff/二进制/无测试变更）+ 可选 AI agent 审查（失败降级）                                                                                             |
| 安全围栏                                       | `plugins/dsh-shared/lib/fence.js`                                                  | 所有 API 请求 loopback 信任围栏（与 /api 网关一致契约）                                                                                                                                                                                                                        |
