# 安全护栏（dsh-my-guard）

> 源码：`plugins/dsh-my-guard/` · [插件 README](../../plugins/dsh-my-guard/README.md) · [文档索引](../索引.md)

## 功能

三类主动防护：**执行前护栏**（破坏性命令执行前拦截或确认）、**安装前投毒扫描**（可疑脚本 / 密钥 / 恶意依赖告警）、**提示注入检测**（prompt injection / jailbreak 命中告警）。

## 安装

```bash
dsh plugin --profile web add dsh-my-guard --trust-lockfile
```

## 关键配置

| 配置键                               | 作用                                                                                       |
| ------------------------------------ | ------------------------------------------------------------------------------------------ |
| `mode`                               | 护栏模式：`observe` 只告警并透传（默认）/ `ask` 触发原生审批确认后才执行 / `deny` 直接拦截 |
| `poisonScan` / `injection`           | 投毒扫描自动联动、提示注入检测开关（默认均开）                                             |
| `notifyEnabled` / `notifyCooldownMs` | 高严重级告警经 dsh-my-notify 推送，以及同类型通知冷却                                      |
| `customRules`                        | 自定义护栏规则（JSON 字符串；在侧边栏「安全护栏」面板编辑保存）                            |

**可视化编辑**：设置 → 插件 →「安全护栏」页签编辑 `mode` / `poisonScan` / `injection` / 通知设置（冷却按秒编辑、写回毫秒），保存即写回 profile patch 并热生效；`customRules` 正则在侧边栏「安全护栏」面板编辑（设置页只显示条数）。非法值一律回退默认，不会写坏配置。

## 主要能力

- **执行前护栏**：匹配 rm -rf /、mkfs、写块设备、fork 炸弹、chmod 777 /、关机重启、下载内容直接管道执行等破坏性模式；
- **投毒扫描**：检查 package.json 可疑脚本、恶意依赖名、文件内密钥模式与可疑扩展名；tarball 解压到临时目录扫描，不执行包内代码；`dsh plugin add` 时自动联动，也可手动扫描；
- **注入检测**：规则 + 启发式识别忽略先前指令、覆盖系统提示词、越狱、敏感信息外传、编码混淆等，自动检测用户消息，也可手动检测；
- **告警与面板**：告警持久化到 `$DSH_HOME/guard/alerts.json`（上限 500 条 FIFO，防抖 + 原子写 + 重启恢复），侧边栏页签展示告警列表与两个扫描工具，可标记已确认。
