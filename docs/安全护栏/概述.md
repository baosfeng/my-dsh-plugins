# 安全护栏（dsh-my-guard）

> 模块文档：`docs/安全护栏/` — 源码：`plugins/dsh-my-guard/`

**dsh-my-guard** 是 DSH 安全护栏插件（拆分自 issue #43 生态调研，对应 issue #52）：**执行前护栏**（破坏性命令执行前拦截/确认）、**安装前投毒扫描**（可疑脚本/密钥/恶意依赖告警）、**提示注入检测**（prompt injection / jailbreak 命中告警）。

## 业务场景映射

| 业务关键词                                         | 入口                                                              | 说明                                                                                                                                                                                                                                                                                                   |
| -------------------------------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 执行前护栏 / 破坏性命令 / rm -rf / 拦截 / 确认     | `plugins/dsh-my-guard/lib/guard.js`                               | 监听 `tools/pre-execute`（waterfall）：bash 命令匹配破坏性模式（rm -rf /、mkfs、dd 写设备、fork 炸弹、chmod 777 /、chown -R、关机/重启、写块设备、curl\|sh）→ 记录 high 告警；默认 observe 只读观察透传 next()，`mode: 'ask'` 返回 `{ kind: 'ask' }` 触发 DSH 原生审批确认，`mode: 'deny'` 直接拦截    |
| 投毒扫描 / 可疑脚本 / 密钥 / 恶意依赖 / 安装前扫描 | `plugins/dsh-my-guard/lib/poison.js`                              | 纯函数扫描引擎：`scanPackage(dir)`（package.json scripts 可疑命令 + 恶意依赖名 + 文件密钥模式 + 可疑扩展名）、`scanTarball(path)`（tar 解压到临时目录，不执行包内代码）；`dsh plugin add` 命令自动联动（link:/本地路径直接扫，包名经 npm registry 下载 tarball 扫描），`POST /guard/api/scan` 手动扫描 |
| 提示注入 / prompt injection / jailbreak / 越狱检测 | `plugins/dsh-my-guard/lib/injection.js`                           | 规则 + 启发式检测（忽略先前指令/系统提示词覆盖/越狱/角色越权/敏感信息外传/编码混淆/禁用安全机制）；监听 `session/event` 的 `user/message`（过滤插件注入消息）自动检测，`POST /guard/api/scan-prompt` 手动检测                                                                                          |
| 告警记录 / 告警持久化 / 用户确认                   | `plugins/dsh-my-guard/lib/store.js`                               | 告警持久化 `$DSH_HOME/guard/alerts.json`（防抖 + 原子写 + 重启恢复），上限 500 条 FIFO；`POST /guard/api/alerts/confirm` 标记已确认（用户确认机制）                                                                                                                                                    |
| 安全护栏面板                                       | `plugins/dsh-my-guard/lib/client.js`（`dsh-my-guard:guard` 页签） | 侧边栏：告警列表（类型徽标 + 严重度 + 时间 + 确认按钮）+ 投毒扫描工具 + 提示注入检测工具；可见时 5s 轮询、隐藏暂停                                                                                                                                                                                     |
| 安全围栏                                           | `plugins/dsh-shared/lib/fence.js`                                 | 所有 API 请求 loopback 信任围栏（与 /api 网关一致契约）                                                                                                                                                                                                                                                |

## 护栏模式

| 模式         | 配置值            | 行为                                                                     |
| ------------ | ----------------- | ------------------------------------------------------------------------ |
| 观察（默认） | `mode: 'observe'` | 只读观察：破坏性命令记录告警，工具照常执行（不改变工具/审批流程）        |
| 确认         | `mode: 'ask'`     | 破坏性命令返回 `{ kind: 'ask' }` 触发 DSH 原生审批流程，用户确认后才执行 |
| 拦截         | `mode: 'deny'`    | 破坏性命令直接拦截（工具返回错误）                                       |
