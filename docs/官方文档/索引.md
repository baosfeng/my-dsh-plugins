**刷新本地参考源**（改动前先跑，避免按旧文档写代码）：

```bash
git -C ~/.dsh-refs/deepseek-harness pull --depth 1 || \
  git clone --depth 1 https://github.com/deepseek-ai/deepseek-harness.git ~/.dsh-refs/deepseek-harness
```

**版本基线**：本目录精编基于官方 `0.1.6-alpha.1`；本机安装的 `@deepseek-ai/dsh` 见 `dsh --version`。两者不一致时以**本机实际运行的包**为准（`node_modules` 里读源码），文档只作方向指引。

## 十、怎么查（检索命令）

```bash
cd ~/.dsh-refs/deepseek-harness

grep -rn "关键词" docs --include=*.zh.md    # 全库搜中文文档
grep -rn "关键词" docs/subsystems           # 只在子系统参考里搜
ls docs/subsystems                          # 列全部子系统页
grep -n "工具名\|配置键" docs/tool-catalog.zh.md docs/config-catalog.zh.md   # 目录检索
```

> **不要凭名字猜 API 语义**：先在 [宿主API速查](宿主API速查.md) 定位所属子系统页，再读该页的类型定义与生成的 Cordis API 小节。
>
> **中文文档不要照抄英文版的标题锚点**：锚点由标题文本生成，中文标题生成的是中文 slug，英文锚点（如 `#loader-configuration`）挂到 `.zh.md` 上必然失效。要精确跳到小节就链英文 `.md`，否则只链文件、不写锚点。
>
> 唯一例外：子系统的生成区有显式锚点 `<a id="cordis-surface"></a>`，中文页同样可用 `#cordis-surface`。
