# 插件 README 模板

> ⚠️ **何时阅读：** 新建插件，或修改任一 `plugins/<包名>/README.md` 时对照本模板。

## 标准章节

| 章节              | 必选 | 说明                                                                                        |
| ----------------- | ---- | ------------------------------------------------------------------------------------------- |
| 标题 + 生态 badge | ✅   | `# <npm 包名>` + shields.io badge                                                           |
| 效果截图          | ✅   | `assets/` 下真实截图，`<div align="center">` 居中带 alt（发版门禁 3b 强制）                 |
| 一句话简介        | ✅   | 加粗，一两行说明插件做什么                                                                  |
| `## 功能`         | ✅   | 编号列表，server / client 分端标注                                                          |
| `## 安装`         | ✅   | **必须含** `dsh plugin --profile web add <包名>`（`check:docs` 强制），再给 link / 手动方式 |
| `## 配置`         | ✅   | 配置键 + 一句话作用；无配置项也要显式写「无配置项」                                         |
| `## 行为与边界`   | 可选 | 只写对使用者有影响的行为、降级与已知限制，不写宿主内部实现                                  |
| `## 相关文档`     | ✅   | 指向 `../../docs/<模块>/概述.md` 与本插件 `CHANGELOG.md`                                    |

## 精简要求（强制）

- 正文 ≤200 行；删 issue/PR 编号、日期、复测记录、旧版本对照。
- 删宿主内部实现细节（事件名、DOM 结构、内部状态文件）、函数与文件清单、目录树。
- 不写 node/npm/git/React 通用常识；同一信息只留一处，模块文档写过的用指针。
- 总则见[文档规范](文档规范.md)。

## 路径与图片约定

- README 在 `plugins/<包名>/README.md`，引用仓库文档用 `../../docs/<模块>/概述.md`。
- 截图两种形态（发版门禁均支持，文件必须真实存在）：相对路径 `./assets/xxx.png`；unpkg 绝对 URL `https://unpkg.com/<包名>/assets/xxx.png`（npm 包页面可显示，推荐）。
- 无 UI 产物的插件在 `package.json` 声明 `"dsh": { "ui": false, "uiReason": "…" }` 豁免发版门禁（与 `dsh.client` 互斥，缺 `uiReason` 会被拒）；README 仍需说明「无 UI」并给出可复核的生效证据。
- 模块文档引用插件截图用 `../../plugins/<包名>/assets/xxx.png`。
- `package.json` 的 `description` 建议中文在前、英文在后。

> 本文件是插件 README 的唯一模板定义；改模板后需检查各插件 README 是否仍对齐。
