# 扩展开发

> ⚠️ **何时阅读：** 开发扩展（新插件）前必读。

## 扩展机制说明

本仓库是 DSH 插件集合仓库，**插件即是扩展**：每个插件是 `plugins/<name>/` 下的自包含 Cordis bundle，通过 `cordis.patch.yml` 挂载到 DSH 宿主。插件经 Cordis 服务名消费宿主能力（`webServer` / `sessions` / `webRuntime` / `slots` / `sidebarRightTabs` / `documentPreviews`），注册侧边栏页签、文件预览器、事件监听与 HTTP 路由，**无需 require 任何第三方侧边栏包**（扩展点语义见 [宿主原生侧边栏扩展点](侧边栏原生API迁移指南.md)）。

## 如何开发扩展

完整流程见 [插件开发技能](../插件开发技能/概述.md)（源码 `skills/dsh-plugin-development/SKILL.md`），核心步骤：

1. **搭骨架**：在 `plugins/<新插件名>/` 建自包含插件包（package.json + cordis.patch.yml + lib/ + README + CHANGELOG + LICENSE），可复制现有插件作参照。
2. **写 package.json**：包名 `dsh-<功能>`，`dsh.bundle.patch` 指向 cordis.patch.yml，peer 依赖声明 cordis / react。
3. **写 Server 端** `lib/index.js`：`export const name / inject / apply(ctx)`；`ctx.on()` 监听事件；`ctx.webServer.register()` 注册路由（handler 先做 loopback 信任围栏）。
4. **写 Client 端** `lib/client.js`：`window.__ModuleLoader__.load` 格式；`ctx.effect(() => ctx.sidebarRightTabs.register(...))` 注册页签类型 + `ctx.slots.register({name:'sidebar.right.pane.tab', key})` 注册面板席位。
5. **写测试**：`test/` 下放纯 Node 冒烟测试（mock ctx / webServer / slots / sidebarRightTabs）。
6. **本地验证**：`dsh plugin --profile web add link:<路径>/plugins/<新插件名>` → 硬刷新浏览器。
7. **发布**：版本号 + CHANGELOG → tag `<包名>@v<版本>` → GitHub Release（见 [发版流程](发版流程.md)）。

## 已提供的扩展点

| 宿主能力           | 消费方式                                                                                                                                                               |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 原生侧边栏页签类型 | client 端 `ctx.sidebarRightTabs.register({id,kind,title,guide})` + `ctx.slots.register({name:'sidebar.right.pane.tab', key})`（inject `['slots','sidebarRightTabs']`） |
| 原生文件预览器     | client 端 `ctx.documentPreviews.register({id,extensions,priority,title,loading})`——只声明认领的后缀与加载模式，**字节由宿主 document owner 读取**                      |
| 原生右栏导航       | client 端 `ctx.sidebarRight.openTab(kind)` / `openResource(address)` / `isExpanded()`（注意会话表面未挂载时 `openTab` 会 throw）                                       |
| webServer 路由     | server 端 `ctx.webServer.register`（HTTP API）                                                                                                                         |
| DSH 事件           | server 端 `ctx.on`（如 `fs/observed`）                                                                                                                                 |
