# 扩展开发

> ⚠️ **何时阅读：** 开发扩展（新插件）前必读。

## 扩展机制说明

本仓库是 DSH 插件集合仓库，**插件即是扩展**：每个插件是 `plugins/<name>/` 下的自包含 Cordis bundle，通过 `cordis.patch.yml` 挂载到 DSH 宿主。插件可消费宿主服务（`webServer` / `sessions` / `webRuntime` / `slots` / `sidebarRightTabs` / `documentPreviews`），注册侧边栏页签、文件预览器、事件监听与 HTTP 路由。

> **侧边栏扩展点（issue #187）**：轻量页签插件（`dsh-ts-example` / `dsh-my-guard` / `dsh-my-context` / `dsh-my-observability` / `dsh-task-reliability` / `dsh-my-guardian`）已从第三方 `dsh-better-sidebar` 迁到**宿主原生扩展点**——`inject = ['slots', 'sidebarRightTabs']`，用 `ctx.sidebarRightTabs.register({id,kind,title,guide})` + `ctx.slots.register({name:'sidebar.right.pane.tab',key:id}, Body)` 注册。原生能力经 Cordis 服务名获取，**无需 require 任何 `@deepseek-ai/dsh-client-ui-*` 包**（官方生产范本：`dsh-client-ui-sidebar-files/lib/client.js:681-711`）。`dsh-file-activity` 也已迁移（批 2）：页签 + `documentPreviews` 元数据 + 自实现浮窗（`shell.overlay` 席位）+ 自绘设置页（`settings.plugins.tab`）——见 [侧边栏原生 API 迁移指南](侧边栏原生API迁移指南.md)。

## 如何开发扩展

完整流程见 [插件开发技能](../插件开发技能/概述.md)（源码 `skills/dsh-plugin-development/SKILL.md`），核心步骤：

1. **搭骨架**：在 `plugins/<新插件名>/` 创建自包含插件包（package.json + cordis.patch.yml + lib/ + README + CHANGELOG + LICENSE），可复制现有插件作参照。
2. **写 package.json**：包名 `dsh-<功能>`，`dsh.bundle.patch` 指向 cordis.patch.yml，peer 依赖声明 cordis / react（侧边栏页签走原生扩展点时**不需要**任何第三方侧边栏依赖）。
3. **写 Server 端** `lib/index.js`：`export const name / inject / apply(ctx)`；`ctx.on()` 监听事件；`ctx.webServer.register()` 注册路由（handler 先做 loopback 信任围栏）。
4. **写 Client 端** `lib/client.js`：`window.__ModuleLoader__.load` 格式；`ctx.effect(() => ctx.sidebarRightTabs.register(...))` 注册页签类型 + `ctx.slots.register({name:'sidebar.right.pane.tab', key})` 注册面板席位。
5. **写测试**：`test/` 下放纯 Node 冒烟测试（mock ctx / webServer / slots / sidebarRightTabs）。
6. **本地验证**：`dsh plugin --profile web add link:<路径>` → 硬刷新浏览器。
7. **发布**：版本号 + CHANGELOG → tag `<包名>@v<版本>` → GitHub Release。

## 已提供的扩展点

> 已无任何插件依赖第三方 `dsh-better-sidebar`（issue #187 两批均已完成；迁移映射见 [侧边栏原生 API 迁移指南](侧边栏原生API迁移指南.md)）。

| 宿主能力           | 说明                                                                 | 消费方式                                                                                                                                                              |
| ------------------ | -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 原生侧边栏页签类型 | 在侧边栏注册新页面（含指南页胶囊与相对顺序）                         | client 端 `ctx.sidebarRightTabs.register({id,kind,title,guide})` + `ctx.slots.register({name:'sidebar.right.pane.tab',key})`（inject `['slots','sidebarRightTabs']`） |
| 原生文件预览器     | 声明本插件认领的文件后缀与加载模式（字节由宿主 document owner 读取） | client 端 `ctx.documentPreviews.register({id,extensions,priority,title,loading})`（inject `[documentPreviews]`；`dsh-file-activity` 已用）                            |
| 原生右栏导航       | 打开页签/资源、读列状态                                              | client 端 `ctx.sidebarRight.openTab(kind)` / `openResource(address)` / `isExpanded()`（inject `[sidebarRight]`；`dsh-file-activity` 自动打开用）                      |
| webServer 路由     | 插件 HTTP API                                                        | server 端 `ctx.webServer.register`                                                                                                                                    |
| DSH 事件           | 监听宿主事件（如 `fs/observed`）                                     | server 端 `ctx.on`                                                                                                                                                    |
