## 四、现状总评

- **基线良好**：现有冒烟测试全绿、测试质量较高（真实代码 + mock 边界），说明项目底子是好的。
- **最大风险**：门禁 4/5/8 无工具实测（复杂度、大小、覆盖率），超长文件（916 行）持续积累复杂度债；无 Gherkin/变异测试，验收仅靠冒烟。
- **防复发原则已入规**：门禁 9（复现测试 RED→GREEN→保留）已写入规范，后续所有 bug 修复都必须先写复现测试。
