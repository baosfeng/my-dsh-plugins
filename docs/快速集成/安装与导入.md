# 安装与导入

> ⚠️ **何时阅读：** 安装插件到 DSH 前必读。

## 环境要求

- DSH（DeepSeek Harness）已安装
- Node.js ≥ 20
- 浏览器端需 DSH web profile
- 侧边栏类插件（如 dsh-file-activity）依赖 `dsh-better-sidebar`——已作为 `dependencies` 级联自动安装，无需手动装（见 [依赖级联安装机制](../踩坑/DSH插件依赖级联安装机制.md)）

## 方式一：dsh plugin（推荐）

```sh
# 1) 克隆本仓库（任意目录）
git clone https://github.com/baosfeng/my-dsh-plugins.git
# 2) 以本地 link 方式安装（<仓库路径> 为克隆目录，<插件目录> 为插件名）
dsh plugin --profile web add link:<仓库路径>/plugins/<插件目录>
```

装完后**硬刷新浏览器**（Cmd/Ctrl+Shift+R）。

> 已发布 npm 的插件也可直接 `dsh plugin --profile web add <npm包名>`（各插件 README「安装」章节）。
> 编辑 profile 的 `cordis.patch.yml` 会通过 Cordis HMR 热挂载 server 端，无需重启 `dsh web`；client 端在页面刷新后生效。

## 方式二：手动（依赖 + patch）

1. 克隆本仓库后，在 `~/.dsh/profiles/web/package.json` 的 dependencies 增加（以 dsh-file-activity 为例，`<仓库路径>` 为克隆目录）：

```json
{
  "dependencies": {
    "dsh-file-activity": "link:<仓库路径>/plugins/dsh-file-activity"
  }
}
```

2. 在 `~/.dsh/profiles/web` 下执行 `pnpm install`
3. 在 `~/.dsh/profiles/web/cordis.patch.yml` 增加挂载行：

```yaml
- insert:
    - id: file-activity # 挂载 id 各插件不同，见插件 cordis.patch.yml
      name: 'dsh-file-activity'
```

> 各插件的运行时依赖（cordis / react / better-sidebar 等）以插件 README「依赖」章节为准。
