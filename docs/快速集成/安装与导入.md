# 安装与导入

> ⚠️ **何时阅读：** 安装插件到 DSH 前必读。
> 本指南适用于仓库内全部插件（`plugins/<插件名>/`，npm 包名与目录名一致），以下 `<插件名>` 替换为目标插件（如 `dsh-file-activity`、`dsh-my-notify`）。

## 环境要求

- DSH（DeepSeek Harness）已安装
- `dsh-better-sidebar` v0.12+（推荐 v0.14，仅侧边栏类插件需要）
- Node.js ≥ 20
- 浏览器端需 DSH web profile

## 方式一：dsh plugin（推荐）

```sh
# 1) 克隆本仓库（任意目录）
git clone https://github.com/baosfeng/my-dsh-plugins.git
# 2) 以本地 link 方式安装（将 <仓库路径> 替换为上面的克隆目录）
dsh plugin --profile web add link:<仓库路径>/plugins/<插件名>
# 或从 npm 安装（已发布的插件）
dsh plugin --profile web add <插件名>
```

装完后**硬刷新浏览器**（Cmd/Ctrl+Shift+R）。

## 方式二：手动（依赖 + patch）

1. 克隆本仓库后，在 `~/.dsh/profiles/web/package.json` 的 dependencies 增加（将 `<仓库路径>` 替换为克隆目录）：

```json
{
  "dependencies": {
    "<插件名>": "link:<仓库路径>/plugins/<插件名>"
  }
}
```

2. 在 `~/.dsh/profiles/web` 下执行 `pnpm install`
3. 在 `~/.dsh/profiles/web/cordis.patch.yml` 增加挂载行：

```yaml
- insert:
    - id: <挂载 id，见插件 cordis.patch.yml>
      name: '<插件名>'
```

> 编辑 profile 的 `cordis.patch.yml` 会通过 Cordis HMR 热挂载 server 端，无需重启 `dsh web`；client 端在页面刷新后生效。
> 各插件挂载 id 与依赖声明见对应 `plugins/<插件名>/cordis.patch.yml`、`package.json` 及插件 README。
