# 思考增强（dsh-think-zh-expand）

> 源码：`plugins/dsh-think-zh-expand/` · [插件 README](../../plugins/dsh-think-zh-expand/README.md) · [md 渲染](../md渲染/概述.md) · [文档索引](../索引.md)

## 功能

让 agent 的思考与回复始终使用中文，思考内容默认展开显示。

## 安装

```bash
dsh plugin --profile web add dsh-think-zh-expand --trust-lockfile
```

Markdown 渲染走宿主官方 baseline 组件（`@deepseek-ai/dsh-client-ui-primitives` 的 `MarkdownText`），无需安装其它渲染内核。

## 关键配置

| 配置键            | 作用                                                                                  |
| ----------------- | ------------------------------------------------------------------------------------- |
| `defaultExpanded` | 思考块展开初值（默认开；显式 `false` 时初始折叠，流式生成中仍自动展开、完成后收起） |

也可在 **设置 → 插件 → 思考增强** 可视化编辑，保存写回 profile 的 `cordis.patch.yml` 并热生效；配置缺失或非布尔值一律回退默认开。

## 主要能力

- **强制中文**：注入 system-prompt 指令，reasoning 与回复都用中文，不受用户语言影响；
- **思考默认展开**：替换 `assistant-step` 渲染器，思考块默认展开完整内容，可点击标题行收起，流式生成中保持展开；
- **渲染**：文本块与思考块统一走宿主官方 baseline `MarkdownText`；
- **不跨插件取值**：不 require 其它特性插件、不声明 `dsh.client.external`（官方禁止特性插件互相 runtime-import 值）。

界面文案（`思考`、`工具调用` 等）由官方 zh locale 提供，本插件不再扫 DOM 替换。
