# 思考增强（dsh-think-zh-expand）

> 源码：`plugins/dsh-think-zh-expand/` · [插件 README](../../plugins/dsh-think-zh-expand/README.md) · [md 渲染](../md渲染/概述.md) · [文档索引](../索引.md)

## 功能

让 agent 的思考与回复始终使用中文，思考内容默认展开显示，并把官方界面里硬编码的英文标签中文化。无插件级配置项。

## 安装

```bash
dsh plugin --profile web add dsh-think-zh-expand dsh-md-render --trust-lockfile
```

`dsh-md-render` 可选：不装则文本块回退官方组件渲染。

## 主要能力

- **强制中文**：注入 system-prompt 指令，reasoning 与回复都用中文，不受用户语言影响；
- **思考默认展开**：替换 `assistant-step` 渲染器，思考块默认展开完整内容，可点击标题行收起，流式生成中保持展开；
- **界面中文化**：DOM 词表替换 Thinking / Tool Call / Duration 等硬编码英文，含工具卡片标题与轨迹视图的工具名与描述；
- **渲染**：文本块与思考块统一走 dsh-md-render 的 MarkdownView（表格 / 公式 / 代码块）。
