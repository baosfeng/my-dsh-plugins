# 插件管理（dsh-my-plugin-manager）

> 源码：`plugins/dsh-my-plugin-manager/` · [插件 README](../../plugins/dsh-my-plugin-manager/README.md) · [文档索引](../索引.md)

## 定位

官方已内置完整的插件管理（侧边栏插件页、`dsh plugin` CLI、tool-plugin-manager 的 list/set/install/remove），
且刻意让**设置页插件列表只读**。本插件只补官方没有的三项只读增量，不再重复安装 / 卸载 / 启停 / 清单管理。

## 功能

- **市场搜索**：npm registry 关键词搜索（官方 install 只接受 spec 文本，无市场浏览）；
- **更新检查**：`dsh plugin --profile <p> outdated --json` → 「当前 → 最新」（官方无 outdated / latest 面）；
- **插件详情**：README / 版本历史 / 依赖与对等依赖（peer 缺失高亮）/ 元数据与月下载量，可切换版本查看依赖。

## 安装

```bash
dsh plugin --profile web add dsh-my-plugin-manager --trust-lockfile
```

## 配置

无插件级配置项；profile 名默认 `web`，由启动时的 `--profile` 参数决定。

## 生效与边界

- 更新检查需 PATH 中存在 `dsh` 命令；安装 / 卸载 / 启停请用官方插件页（同一 `dsh plugin` 数据源）；
- 面板挂在官方 slots 扩展点（设置 → 插件），缺扩展点时静默跳过注册，server 端 API 不受影响；
- README 渲染只用宿主官方 baseline `MarkdownText`（平台 seed 模块），缺它时落到本插件 `<pre>`——不跨插件取渲染内核。
