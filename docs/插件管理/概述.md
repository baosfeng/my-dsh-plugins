# 插件管理（dsh-my-plugin-manager）

> 源码：`plugins/dsh-my-plugin-manager/` · [插件 README](../../plugins/dsh-my-plugin-manager/README.md) · [文档索引](../索引.md)

## 功能

在 DSH 设置页统一维护插件生命周期：市场浏览 / 搜索 → 一键安装 / 卸载（复用 dsh CLI 同一数据源）→ 更新检查 → 已安装清单，插件可独立于 DSH 主程序随时更新。

## 安装

```bash
dsh plugin --profile web add dsh-my-plugin-manager --trust-lockfile
```

## 配置

无插件级配置项；profile 名默认 `web`，由启动时的 `--profile` 参数决定。

## 主要能力

- **市场**：按关键词搜索 npm 上的插件，展示版本与描述，点「安装」即写入 profile；
- **已安装**：列出用户安装的插件与版本，支持逐行卸载；官方与内置命名空间自动过滤；
- **更新检查**：解析 pnpm outdated 结果，展示「当前 → 最新」；
- **生效时机**：安装 / 卸载落盘即时生效，新插件下次启动 DSH 时加载（运行时热挂载由 dsh-my-guardian 负责）。

## 边界

- 安装 / 卸载 / 更新检查通过 spawn 调用 `dsh plugin` 子命令，需 PATH 中存在 `dsh` 命令；
- 面板为可选增强，缺少设置页扩展点时静默跳过注册，server 端 API 不受影响。
