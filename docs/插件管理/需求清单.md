## 2. 用户明确强调过的点

- **纯官方依赖**（issue #22 精神）：client 面板挂在官方 `slots` 扩展点，不依赖 dsh-better-sidebar；server 只用官方 `pluginInventory` / `webServer` / `webRuntime`。
- **同一数据源**（issue #2 兼容性要求）：安装/卸载走 `dsh plugin` CLI 而非手写 patch 编辑，`cordis.patch.yml` 格式保持不变，面板只是其可视化操作层。
- **插件独立于 dsh 发版节奏**：更新检查直接面向 npm registry / pnpm，不依赖 dsh 主程序发版。
