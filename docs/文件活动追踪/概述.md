# 文件活动追踪（dsh-file-activity）

> 源码：`plugins/dsh-file-activity/`（基于 dsh-better-sidebar 页签扩展）· [插件 README](../../plugins/dsh-file-activity/README.md) · [文档索引](../索引.md)

## 功能

在侧边栏新增「文件活动」页签：按 LRU 记录 agent 与侧边栏对文件的读取/新增/修改事件，按绝对路径树形统计次数，点击文件浮窗预览。

## 安装

```bash
dsh plugin --profile web add dsh-file-activity --trust-lockfile
```

装完硬刷新浏览器，侧边栏 `+` 菜单 → 文件活动。

## 主要能力

- **最近访问**：LRU 记录读写事件（每会话最多 5 条，同文件去重并前移），区块可折叠，行内显示相对时间；
- **文件统计**：读/新增/修改次数按绝对路径组织成可折叠树，连续单子目录链压缩为 `a.b.c` 标签；
- **浮窗预览**：代码高亮 / Markdown / 图片 / PDF / 沙箱 HTML，`Esc` 或点击浮窗外关闭；
- **工作区外也能预览**：媒体与文本走插件自身路由，只放行该会话记录过的路径；HTML 走无 same-origin 的双层沙箱；
- **按会话隔离**：前后端均按 sessionId 分桶，切换会话即切数据；页签默认启用。

## 配置

无插件级配置项；页签默认开启，可在侧边栏设置中关闭。

## 数据

状态存 `$DSH_HOME/file-activity.json`（JSON Lines 增量追加 + 阈值原子 compact，500ms 防抖写入）；每会话路径 ≤300、全局路径 ≤20000、会话数 ≤64，LRU 淘汰并计数。
