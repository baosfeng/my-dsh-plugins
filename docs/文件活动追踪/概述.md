# 文件活动追踪（dsh-file-activity）

## 概述

DSH 侧边栏文件活动插件（基于 dsh-better-sidebar 扩展），在 better-sidebar 中新增「文件活动」页签，提供：

- **最近访问**：按 LRU 记录文件读取/新增/修改事件（agent 工具读写 + 侧边栏打开/编辑保存都会记录），每会话最多保留 5 条，同一文件只出现一次（再次访问移到最前）；区块标题可点击折叠。
- **文件统计**：每个文件的「读取 / 新增 / 修改」次数，按文件**绝对路径**组织成树形目录；连续单子目录路径链压缩为点号标签（`a/b/c` → `a.b.c`）；文件夹可折叠；行内显示相对时间。
- **浮窗预览**：点击任意文件弹出浮窗，复用侧边栏内置 viewer 渲染（代码高亮 / Markdown / 图片 / PDF / HTML），点击浮窗外或 `Esc` 关闭。媒体字节（图片/PDF）由插件自身的 `/file-activity/file` 路由提供——按会话记录授权（只放行该会话记录过的路径），因此**工作区外文件（如 `/tmp`）也能预览**；Markdown/代码/HTML 文本优先走侧边栏 `fs.read`（工作区内），被侧边栏拒绝（工作区外等）时自动降级到插件自身文本路由（`/file-activity/file?as=text`，同样按会话记录授权）——**工作区外文本与图片/PDF 一样可预览**；文件已删除/不存在时显示友好提示（「文件不存在或已被删除」），不再暴露 `ENOENT` 等原始系统错误。
- **默认启用**：页签默认开启，每会话首次打开自动打开本页（可在侧边栏设置中关闭）。

## 核心文件

| 文件路径                                  | 名称                                        | 说明                                                                                                                                                                                                                                                                                                  |
| ----------------------------------------- | ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `plugins/dsh-file-activity/lib/index.js`  | server 端（`apply(ctx)`）                   | 监听 `fs/observed` 事件捕获 agent 文件操作；提供 `/file-activity/api` 路由（`stats` / `record` / `clear`）与媒体路由 `/file-activity/file`（图片/PDF 字节，按会话记录授权）；状态按会话持久化到 `$DSH_HOME/file-activity.json`（**JSON Lines 增量 append + 阈值原子 compact**，见下「状态与持久化」） |
| `plugins/dsh-file-activity/lib/client.js` | client 端（`window.__ModuleLoader__.load`） | 通过 `ctx.betterSidebar.registerTab` 注册「文件活动」页签；fetch 拦截捕获侧边栏文件操作并上报；点击文件调用 `ctx.betterSidebar.matchFileViewer` 匹配内置 viewer，浮窗挂载其组件（媒体字节走 `/file-activity/file`）                                                                                   |

## 状态与持久化

- 状态按会话隔离，存于 `$DSH_HOME/file-activity.json`（`DSH_HOME` 未设置时回退 `~/.dsh/`）。
- **格式为 JSON Lines**（issue #197）：每条记录一行 `{"s","p","o","t"}`；累计行数达自适应阈值时原子 compact
  一次（元信息行 + 每会话一行 `{"s","d"}` + 结束行 `=`）。加载时按行序重建（快照行建立基线、事件行重放），
  因此"未 compact 就被 kill"也不丢数据；升级前的单行全量 JSON 快照仍可读取并在首次启动改写为 JSON Lines。
- **写入成本**：单次落盘 ≈ 事件本体字节（实测写放大 1.0×，整改前 2,073×）；compact 频率随快照体积自适应，
  快照成本摊薄到足够多的事件行上。
- **三维入口上限（LRU 淘汰，非静默丢弃）**：每会话路径 ≤ 300、全局路径 ≤ 20000、会话数 ≤ 64；
  淘汰计数在 `store.stats()`（`evictedSessions`/`evictedPaths`/`evictedPathsTotal`）与 warn 日志可见。
- **资源门禁**：本插件已并入 `scripts/resource-smoke.mjs`（CI `resource-smoke` job）的写放大与有界性断言。
- 写入策略：500ms 防抖 + tmp+rename 原子写；卸载时立即刷盘。
- `write` 通过每会话已知文件表区分**新增**（首次接触）与**修改**（再次写入）；`edit` / `str_replace_editor` 记为修改；`read` / `read_image` 记为读取。
- **前端同样按会话隔离**：客户端数据 store 以 `bySession: { [sessionId]: { recent, counts } }` 分桶，页签只读取当前会话自己的桶——新建/切换会话立即显示该会话的数据（新会话为空），不会残留上一个会话的记录。

## 使用方式

安装见 [安装与导入](../快速集成/安装与导入.md)（推荐 `dsh plugin --profile web add link:<仓库路径>/plugins/dsh-file-activity`）。装完后硬刷新浏览器；侧边栏 `+` 菜单 → 文件活动。
