# dsh-file-activity 需求清单

> ⚠️ **每次开发本插件的新功能或修复前，必须逐条对照本清单**：新改动不得破坏任何一条既有需求；涉及"会话隔离 / 重启恢复"的需求变更后必须跑回归验证（见 [构建与测试](../开发指南/构建与测试.md#需求回归强制要求)）。

## 2. 用户明确强调过的点（历史踩坑）

- **「重启之后还能恢复我之前的」**（2026-08-23 再次强调）：重启恢复是最容易被其他改动连带破坏的需求，改动任何持久化/前端数据流后必须回归验证 R1 + R2。
- **「会话残留」**（2026-08-23）：之前新会话会显示上一个会话的文件活动，已通过前端 `bySession` 分桶修复（v0.4.1）。
- 状态文件 `file-activity.json` 损坏/缺字段时降级为全新状态，不崩溃（loadState try/catch）。

## 需求变更记录

- **2026-09-02**：R9 浮窗预览「HTML 内容撑满浮窗」（v0.5.6，issue #111 方案 A）——浮窗尺寸本身不小（`height:76vh; max-height:860px`），但 better-sidebar 的 viewer 组件根元素用 `flex:1` 撑满，而浮窗主体 `.dfa-fp-body` 是块级容器（非 flex），`flex:1` 被忽略；HTML 的 `<iframe>` 因此只按浏览器默认高度（≈150px）顶部渲染一条，下方大量留白（代码/Markdown/图片因内容自然撑高、主体滚动，未暴露此问题）。现 `.dfa-fp-body` 改为 flex 列容器，viewer 的 `flex:1` 子元素（HTML iframe / code / markdown / image）撑满浮窗主体并内部滚动，内容随浮窗尺寸变化自适应，与代码/Markdown/图片预览体验一致。
- **2026-09-01**：R9 浮窗预览补充「失焦自动关闭 + 预览失败自动关闭」（v0.5.5，issue #76）——浮窗此前一直保持显示（预览失败时也挂着），关闭依赖手动点外部/Esc/×，且浮窗内部点击被 `stopPropagation` 完全拦截，用户误以为「关不掉」。现：① document 级 `pointerdown` 监听（capture）点击浮窗外部任意处即关（遮罩 onClick 保留兜底）；② 切换页签（visible=false）自动关闭；③ 预览失败 2.5s 自动关闭，且错误态点击浮窗任意处立即关闭（错误区不再锁死）；④ 头部常驻「点击外部关闭」提示 + 错误面板「即将自动关闭」提示，降低发现成本。
- **2026-09-01**：R9 浮窗预览补充「工作区外文本可预览 + 预览失败优雅降级」（v0.5.4，issue #68）——侧边栏 `fs.read` 只允许 cwd 内路径，agent 读过的工作区外文本（如 `~/.dsh/skills/...`）此前点击预览直接报 `is outside workspace` 原始错误；已删除文件报 `ENOENT`。现文本被拒时自动降级到插件自身 `/file-activity/file?as=text`（按会话记录授权，与媒体路由同一模式）；仍失败时按错误类型显示中文友好提示（「文件不存在或已被删除」/「文件位于工作区外」），原始系统错误不再上屏。
- **2026-08-29**：**移除侧边栏 tab 选中态品牌色覆盖（issue #25 → #60）**——此前为让选中态更醒目（issue #25），插件注入 `[class*="tab"][class*="tabActive"]` 规则把宿主选中 tab 填充为品牌色（浅色 #4176e6 蓝 / 深色 #679efe）；用户实测该蓝色高亮属异常（issue #60），要求「保持原来的状态」。现移除该覆盖，选中 tab 恢复宿主 dsh-better-sidebar 官方样式（`interactive-bg-active` 灰底 + `label-primary` 主文字），仍与未选中 tab 可区分，但不再强制蓝色高亮。已实证：注入时选中 tab `background:rgb(65,118,230)`；移除后 `rgba(38,49,72,0.1)`（宿主灰底）。
- **2026-08-24**：R9 浮窗预览补充「工作区外文件可预览」（v0.4.4 媒体路由修复）——侧边栏 `/sidebar/file` 只允许 cwd 内文件，agent 触碰的 `/tmp` 等工作区外路径此前破图；插件自身 `/file-activity/file` 路由按会话记录授权放行，fence 一致。
- **2026-08-23**：新增 R1 重启恢复强调、R2 会话隔离（v0.4.1 修复）；建立本清单，作为后续开发对照基准。
