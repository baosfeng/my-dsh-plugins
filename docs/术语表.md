# 术语表

my-dsh-plugins 是个人 DSH（DeepSeek Harness）插件集合仓库。以下术语是本项目与 AI agent 协作的共享语言，沟通前先查此表。

## 业务领域

**文件活动（File Activity）**:
侧边栏「文件活动」页签的功能统称：记录文件的读取 / 新增 / 修改事件历史与统计。
_Avoid_: 文件记录、访问日志

**最近访问（Recent）**:
按 LRU 维护的文件访问历史列表，每会话最多 5 条，同一文件只出现一次（再次访问移到最前）。
_Avoid_: 最近文件、历史列表

**文件统计（File Stats）**:
每个文件「读取 / 新增 / 修改」次数的统计，按绝对路径组织成树形目录展示。
_Avoid_: 计数、统计视图

**浮窗预览（Floating Preview）**:
点击文件后弹出的悬浮预览窗，复用侧边栏内置 viewer 渲染（代码高亮 / Markdown / 图片 / PDF / HTML）。
_Avoid_: 弹窗、预览窗口

## 技术领域

**Server 端**:
插件的宿主侧代码（`lib/index.js`），运行在 DSH Node 进程，负责事件监听、HTTP 路由、持久化。
_Avoid_: Host 半（禁止）、服务端

**Client 端**:
插件的浏览器侧代码（`lib/client.js`），运行在页面，负责注册页签 / 预览器等 UI。
_Avoid_: 客户端、前端

**页签（Tab）**:
注册到侧边栏的页面。轻量页签插件走宿主原生扩展点
（`ctx.sidebarRightTabs.register` 注册类型 + `ctx.slots.register({name:'sidebar.right.pane.tab'})`
注册面板席位，如「上下文透镜」「插件守护」）；`dsh-file-activity` 仍走第三方
`ctx.betterSidebar.registerTab`（批 2 排期）。
_Avoid_: 标签页、面板

**预览器（Viewer）**:
侧边栏内置的文件渲染器（代码 / Markdown / 图片 / PDF / HTML），通过 `matchFileViewer` / `openFile` 调用。
_Avoid_: 查看器、渲染器

**LRU（Least Recently Used）**:
最近最少使用淘汰策略，用于最近访问列表（每会话最多 5 条）。
_Avoid_: 最近策略、缓存

**冒烟测试（Smoke Test）**:
`test/host-smoke.mjs` 等纯 Node 测试（mock ctx / webServer），CI 只跑冒烟测试。
_Avoid_: 冒烟、快速测试

**bundle（插件包）**:
`plugins/<name>/` 下自包含的 Cordis 插件包（package.json + cordis.patch.yml + lib/ + README + LICENSE + CHANGELOG）。
_Avoid_: 插件目录、包

**工具型插件（Tool Plugin）**:
注册 agent 可调用函数（`ctx.tools.register(defineTool(...))`）的插件形态，不依赖侧边栏能力。
_Avoid_: 工具插件、函数插件

**defineTool**:
官方 `@deepseek-ai/dsh-tools` 提供的工具定义 API：`{ name, description, parameters, output, execute }`，schema 用属性级 `required` 且对象必须显式 `additionalProperties: false`。
_Avoid_: run 写法（是 `execute` 不是 `run`）
