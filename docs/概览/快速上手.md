# 快速上手

> ⚠️ **何时阅读：** 快速了解本仓库能做什么、怎么装、怎么开发时。

## 1. 安装插件到 DSH

推荐用 `dsh plugin` 以本地 link 方式安装（clone 本仓库后指向仓库内插件目录）；也支持手动依赖 + patch 方式。完整环境要求与两种方式的操作步骤见 [安装与导入](../快速集成/安装与导入.md)。

装完后**硬刷新浏览器**（Cmd/Ctrl+Shift+R）。编辑 profile 的 `cordis.patch.yml` 会在运行中通过 Cordis HMR 热挂载 server 端，无需重启 `dsh web`；client 端在页面刷新后生效。

## 2. 使用文件活动页签

侧边栏 `+` 菜单 → **文件活动**（会话首次自动打开）：**最近访问**（LRU，每会话 5 条）+ **文件统计**（读取/新增/修改次数树形目录）+ **浮窗预览**（复用侧边栏内置渲染）。功能细节与数据机制见 [文件活动追踪](../文件活动追踪/概述.md)。

## 3. 开发新插件

流程与规范（插件形态 / 目录结构 / server+client 两端 / 发布）见 [插件开发技能](../插件开发技能/概述.md)（源码 `skills/dsh-plugin-development/SKILL.md`）；TypeScript 插件照抄 [TS 示例插件](../TS示例/概述.md)。本地验证：`dsh plugin --profile web add link:<绝对路径>/plugins/<新插件名>`。
