# 项目简介

**个人 DSH（DeepSeek Harness）插件集合仓库**：轻量多插件目录，每个插件位于 `plugins/<name>/`，自包含、可独立安装与发布。

## 基本信息

| 项     | 值                                                                                                                                     |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| 项目名 | my-dsh-plugins                                                                                                                         |
| 版本   | 各插件独立 semver（每插件独立版本号与 CHANGELOG，见各插件 `package.json` / `CHANGELOG.md`）                                           |
| 语言   | JavaScript / TypeScript（Node.js ≥ 20，ESM）                                                                                           |
| 类型   | 基础服务（DSH 插件集合）                                                                                                               |
| 技术栈 | Node.js + Cordis 4（插件框架）+ React 18/19 兼容（client 渲染，实际版本由 DSH 运行时决定）+ dsh-better-sidebar（侧边栏扩展服务）       |
| 仓库   | https://github.com/baosfeng/my-dsh-plugins                                                                                             |

> 插件完整清单（含功能简介与需求清单）见 [索引.md](../索引.md)「功能模块」，共 17 个插件。

## 仓库结构

```
├── plugins/                    # 所有插件（每目录一个自包含插件）
│   └── dsh-file-activity/
│       ├── lib/index.js        # server 端入口（事件监听/HTTP 路由/持久化）
│       ├── lib/client.js       # client 端入口（浏览器页签注册）
│       ├── test/               # 单测 + Gherkin 验收（npm test 执行）
│       ├── package.json        # 独立包（exports 分 server/client）
│       ├── cordis.patch.yml    # bundle 挂载补丁
│       └── README.md / CHANGELOG.md / LICENSE
├── skills/                     # 本仓库开发技能（SKILL.md 格式，可安装到 ~/.dsh/skills/）
├── docs/                       # 通用文档与模块文档（导航入口 docs/索引.md）
├── .github/workflows/          # CI（遍历插件测试）与 Release（tag 触发）
└── AGENTS.md                   # AI 代理入口（协作原则 + 强制规则 + 入口）
```

## 发布约定

- 发版命令：`node scripts/release.mjs <插件名> --bump patch --push`（自动 bump 版本 + 生成 CHANGELOG + 同步 README/AGENTS.md 版本号 + 推送 tag）。
- 发布通道：tag `<包名>@v<版本>` 推送后由 `.github/workflows/release.yml` 自动创建 GitHub Release，并配置 `NPM_TOKEN` 时同步发布 npm。
- 安装方式：`dsh plugin --profile web add link:<仓库路径>/plugins/<插件名>`（本地 link）或 npm 安装，详见 [安装与导入](../快速集成/安装与导入.md)。
- 许可：每个插件各自携带 MIT LICENSE；仓库级文档默认 MIT。
