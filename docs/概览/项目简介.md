# 项目简介

**个人 DSH（DeepSeek Harness）插件集合仓库**：轻量多插件目录，每个插件位于 `plugins/<name>/`，自包含、可独立安装与发布。

| 项     | 值                                                                                         |
| ------ | ------------------------------------------------------------------------------------------ |
| 项目名 | my-dsh-plugins                                                                             |
| 语言   | JavaScript / TypeScript（Node.js ≥ 20，ESM）                                               |
| 技术栈 | Node.js + Cordis 4（插件框架）+ React 18/19 兼容（client 渲染，实际版本由 DSH 运行时决定） |
| 版本   | 各插件独立 semver（每插件独立版本号与 CHANGELOG）                                          |
| 仓库   | https://github.com/baosfeng/my-dsh-plugins                                                 |

> 插件完整清单（含功能简介与模块文档）见 [索引.md](../索引.md)「功能模块」。

## 发布与安装约定

- **发版**：`node scripts/release.mjs <插件名> --bump patch --push`（自动 bump 版本 + 生成 CHANGELOG + 同步 README/AGENTS.md 版本行 + 推送 tag），详见 [发版流程](../开发指南/发版流程.md)。
- **发布通道**：tag `<包名>@v<版本>` 推送后由 workflow 自动创建 GitHub Release；配置 `NPM_TOKEN` 时同步发布 npm。
- **安装**：`dsh plugin --profile web add link:<仓库路径>/plugins/<插件名>`（本地 link）或从 npm 安装，详见 [安装与导入](../快速集成/安装与导入.md)。
- **许可**：每个插件各自携带 MIT LICENSE；仓库级文档默认 MIT。
