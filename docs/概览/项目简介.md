# 项目简介

**个人 DSH（DeepSeek Harness）插件集合仓库**：轻量多插件目录，每个插件位于 `plugins/<name>/`，自包含、可独立安装与发布。

## 基本信息

| 项     | 值                                                                                                                                            |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 项目名 | my-dsh-plugins                                                                                                                                |
| 语言   | JavaScript（Node.js ≥ 20，ESM）；TypeScript 示例（dsh-ts-example，issue #47）                                                                 |
| 类型   | 基础服务（DSH 插件集合）                                                                                                                      |
| 技术栈 | Node.js + Cordis 4（插件框架）+ React 18/19 兼容（client 渲染，实际版本由 DSH 运行时决定，当前 18.3.1）+ dsh-better-sidebar（侧边栏扩展服务） |
| 仓库   | https://github.com/baosfeng/my-dsh-plugins                                                                                                    |

## 插件列表

共 18 个插件（plugins/，含 agent preset 与共享工具包）。完整列表、当前版本与简介见根 [README](../../README.md)；功能模块文档导航见 [索引.md](../索引.md)。

> 各插件独立 semver，版本以 `package.json` 为准（每次 release 自动更新，文档不维护版本列表）。

## 发布约定

- **双通道发布**：GitHub Release（tag 触发自动打包）+ npm 官方 registry（release.yml 自动 `npm publish`）。完整流程见 [发版流程](../开发指南/发版流程.md)。
- 每个插件独立版本号（semver）、独立 CHANGELOG（Keep a Changelog 格式）。
- 许可：每个插件各自携带 MIT LICENSE；仓库级文档默认 MIT。
