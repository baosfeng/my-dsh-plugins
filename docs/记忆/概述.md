# 记忆（dsh-my-memory）

> 源码：`plugins/dsh-my-memory/` · [插件 README](../../plugins/dsh-my-memory/README.md) · [文档索引](../索引.md)

## 功能

把用户偏好与项目约定持久化为全局 / 项目两级记忆：全局记忆在会话开始时注入系统提示词（agent 始终携带），设置页可视化面板管理（写操作必须用户确认），并提供 `memory_query` 只读查询与 `memory_save` 保存工具。

## 安装

```bash
dsh plugin --profile web add dsh-my-memory --trust-lockfile
```

## 关键配置

| 配置键             | 作用                                                                   |
| ------------------ | ---------------------------------------------------------------------- |
| `maxItems`         | 注入系统提示词的条数上限（默认 5，按相关性 + 时效性 + 置信度评分选取） |
| `maxDescLength`    | 单条注入长度上限（字符，按语义截断，不截断在句子中间）                 |
| `maxEntryLength`   | 建议的单条记忆长度上限（超出时面板提示精简，不拒绝保存）               |
| `autoLearn`        | 会话结束后自动提取记忆候选进「待确认」区（默认关，确认后才写入）       |
| `extractor`        | 提取方式：`rule` 确定性规则提取器（默认）/ `llm` 预留占位              |
| `proactivePropose` | 是否引导 agent 主动向用户提议保存记忆（默认关）                        |

## 主要能力

- **两级存储**：全局存 `$DSH_HOME/memory.json`；项目记忆按项目根路径哈希集中存 `$DSH_HOME/memory/projects/`，旧的项目内记忆文件首次访问时自动迁移；原子写 + 防抖 + 重启恢复；
- **注入**：只注入全局记忆，会话开始即生效，记忆变更后下一轮生效；
- **面板**：全局 / 项目分区、概要 + 详情两级展示，条目带分类徽标、置信度、矛盾警示与演进历史，保存与删除走自定义确认 UI；
- **工具**：`memory_query` 只读查询（含项目记忆）；`memory_save` 每次调用都经确认门触发原生审批，绝不静默变更；
- **候选**：开启 `autoLearn` 后会话结束只把候选写进独立文件，确认或拒弃都由用户显式动作；同主题合并提升置信度、分歧标记矛盾、90 天未用降权。
