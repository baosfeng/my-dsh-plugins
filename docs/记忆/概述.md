# 记忆（dsh-my-memory）

> 源码：`plugins/dsh-my-memory/` · [插件 README](../../plugins/dsh-my-memory/README.md) · [文档索引](../索引.md)

## 功能

把用户偏好与项目约定持久化为全局 / 项目两级记忆：全局记忆在会话开始时注入系统提示词（agent 始终携带），设置页可视化面板管理（写操作必须用户确认），并提供 `memory_query` 只读查询与 `memory_save` 保存工具。

## 安装

```bash
dsh plugin --profile web add dsh-my-memory --trust-lockfile
```

## 关键配置

| 配置键             | 作用                                                                   |
| ------------------ | ---------------------------------------------------------------------- |
| `maxItems`         | 注入系统提示词的条数上限（默认 5，按相关性 + 时效性 + 置信度评分选取） |
| `maxDescLength`    | 单条注入长度上限（字符，按语义截断，不截断在句子中间）                 |
| `maxEntryLength`   | 建议的单条记忆长度上限（超出时面板提示精简，不拒绝保存）               |
| `proactivePropose` | 是否引导 agent 主动向用户提议保存记忆（默认关）                        |
| `maxPromptItems`   | 注入的全局提示词条数上限（默认 20，超出不注入 + warn）                 |
| `maxPromptLength`  | 单条提示词正文上限（字符，默认 1000，超出截断 + warn）                 |

## 主要能力

- **两级存储**：全局存 `$DSH_HOME/memory.json`；项目记忆按项目根路径哈希集中存 `$DSH_HOME/memory/projects/`，旧的项目内记忆文件首次访问时自动迁移；原子写 + 防抖 + 重启恢复；
- **注入**：只注入全局记忆，会话开始即生效，记忆变更后下一轮生效；
- **面板**：全局记忆 / 项目记忆 / 全局提示词三个 tab；条目概要 + 详情两级展示，带分类徽标、置信度、矛盾警示与演进历史；新增与编辑为多行自适应输入框，保存与删除走居中确认弹层；项目 tab 随当前会话项目根自动加载；
- **工具**：`memory_query` 只读查询（含项目记忆）；`memory_save` 每次调用都经确认门触发原生审批，绝不静默变更；
- **渐进合并**：同主题多次保存提升置信度、分歧标记矛盾、90 天未用降权（自动学习候选已移除）。

## Agent 记忆（issue #502，第四套体系）

**定位**：agent 自主维护的**跨会话记忆**——记住下次会话还用得上的信息与用户偏好。与上面三套（全局记忆 / 项目记忆 / 全局提示词）**完全隔离**：独立目录、独立工具、独立元数据、独立面板 tab。

**核心差异：零常驻注入。** 全局记忆是固定 top-5 注入，而 agent 记忆**不注入任何正文**——系统提示词里只有一段固定规则说明（order -80），正文只在 agent 主动调用 `agent_memory_read` 时才进入上下文。不命中则一分 token 都不花。

**文件是存储，不是接口。** 正文是纯 markdown（不带日期、不带 id、不带 frontmatter）；元数据（创建时间 / 最后读取 / 读取次数 / 归档）单独存 `index.json`，**agent 读不到也写不到**。理由：时间戳与热度若可被 agent 篡改，遗忘机制就形同虚设。

```text
$DSH_HOME/agent-memory/
├── index.json              # 元数据（agent 不可见、不可写）
├── MEMORY.md               # 索引：一行一个文件 + 什么时候该读
├── user.md                 # 用户偏好
├── feedback.md             # 被纠正过的做法 + 正确做法
├── projects/<id>/
│   ├── MEMORY.md
│   ├── decisions.md        # 决策 + 为什么
│   └── pitfalls.md         # 坑 + 怎么绕
└── archive/                # 冷记忆归档区（不列出；面板可见并可恢复）
```

**工具**（4 个，路径限定白名单内，逃逸结构上不可能）：`agent_memory_list` / `agent_memory_read` / `agent_memory_write` / `agent_memory_delete`。成功只返回 `ok`——不回显、不汇报、不占上下文。每个工具都按宿主契约声明 `output { schema, render }`（**宿主 `tools.register()` 强制要求，缺了直接抛 `TypeError` 注册不上**，见 `test/host-register-contract.mjs`）。

**三道硬门禁**：尺寸红线（单文件 4 KB / 60 条 / 单条 100 字符，超限**报错**要求先整理）、敏感信息扫描（密钥 / token / 密码 / 私钥拒写）、并发写串行化。

**遗忘机制**：每次 agent 读取由系统自动累计 `readCount` 与 `lastReadAt`；超过 `archiveDays`（默认 180 天）未读即移入 `archive/`、不再列出、不进索引。**面板浏览不计入** readCount——人肉翻看不该让死记忆续命。

**归档可恢复**：归档后 **agent 仍读不到**（遗忘语义不变），但面板能读到正文并一键恢复（正文搬回原位 + 清归档标记）；GET 列表返回 `archived: true` 与正文；重新写入同名文件也会自动复活。归档不再是「凭空消失」。

**写入原则**硬编码在系统提示词里（agent 改不了）：一句话一条、只写通用的、不写能从代码推导的、决策必须带理由、先读再写不重复、不写日期、敏感信息零容忍、**宁缺毋滥（空文件是合法的）**。

**冲突处理同样交给 agent**（系统不做查重、不设矛盾状态、不阻断写入）：写入协议先**分清真假矛盾**——不同场景/不同对象的偏好能用限定语共存就别删（「前端用 pnpm，后端用 npm」）；真矛盾（同一对象、同一维度、互斥取值）写新的删旧的，演进有解释价值时写成「（原 X，现 Y）」一句，绝不留两条并存；**写满（超限报错）时先整理**（合并近义、删被取代、精简措辞）再写——尺寸红线报错即整理触发器。

**面板**：设置页第四个 tab「Agent 记忆」——文件视图（正文等宽展示、可直接编辑）+ 元数据可见（创建 / 最近读取 / 读取次数 / 归档标记）。这是「给用户了解原因」的唯一落点。

| 配置键 | 默认 | 作用 |
| ------ | ---- | ---- |
| `agentMemory.enabled` | `true` | 是否启用 agent 记忆 |
| `agentMemory.archiveDays` | `180` | 冷记忆归档阈值（天）；归档项面板可见并可恢复 |

## 全局提示词（与记忆隔离）

「全局提示词」是**必须始终生效的指令**，与记忆（「可能有用的事实，按相关度挑选」）语义相反，因此两者独立：独立文件 `$DSH_HOME/memory/prompts.json`、独立设置分区、独立端点 `/my-memory/api/prompts`。

| 维度 | 全局记忆 | 全局提示词 |
| ---- | -------- | ---------- |
| 检索 | 相关性 + 时效性 + 置信度评分取 top-N、逐条摘要截断 | 无检索：**全量按序**注入，不评分不截断 |
| 写入 | agent 工具 `memory_save` | **只有设置页可写**，agent 无写工具 |
| 注入 | section `dsh-my-memory`，order -95 | section `dsh-my-memory:prompts`，order -85 |

- 启停：`enabled:false` 即不注入；全部停用时 section 返回空串（宿主丢弃空 section，零成本）；排序用「上移 / 下移」写回 `order`。
- 生效：注入读内存态，保存后**下一轮组装即生效**，无需重启或重新注册。
- 迁移：`prompts.json` 不存在时写入内置种子 `builtin:think-zh`（中文思考指令，默认启用）；文件已存在不补种，用户删除后不复活。
- 上限：`maxPromptItems` / `maxPromptLength` 是安全阀，超出条目不注入、超长正文截断（都带 warn）。
