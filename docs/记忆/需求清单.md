## 2. 用户明确强调过的点

- **纯官方依赖**（issue #22 精神）：client 面板挂在官方 `slots` 扩展点（`settings.plugins.tab`），不依赖 dsh-better-sidebar；server 端只用官方 `ctx.systemPrompt` / `ctx.tools` / `webServer` / `webRuntime` / `sessions` 服务；工具定义直接构造（不导入 `@deepseek-ai/dsh-tools`——本仓库插件只解析 Node 内置模块与相对路径）。
- **记忆绝不静默变更**：所有写操作（新增/修改/删除/工具保存/**自动提取候选的确认与拒弃**）必须经用户确认。面板经 `POST /my-memory/api/memory` 强制 `confirmed: true`；`memory_save` 工具经 `tools/pre-execute` 确认门（`{ kind: 'ask' }` 触发 DSH 原生审批）；自动提取（issue #78）只产生「待确认候选」，确认/拒弃经 `POST /my-memory/api/candidates/{confirm,dismiss}` 且强制 `confirmed: true`——确认前绝不写入。
- **注入有上限**：全局记忆注入系统提示词受条数（`maxItems`）与单条长度（`maxDescLength`）双重上限，避免提示词膨胀。
- **自动提取默认关（issue #78）**：`autoLearn` 默认 `false`（用户显式开启才自动提取；提取不影响对话流程、不静默写入）；`extractor` 默认 `rule`（确定性规则提取器，CI/离线可测），`llm` 为预留占位。
