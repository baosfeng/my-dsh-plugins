# 隔离实例"少加载插件"假失败（dshmarket 独立启停状态）

## 症状

用 `node scripts/verify-real-profile.mjs --addons plugins/<A> --addons plugins/<B> ...` 起隔离实例后：

- 浏览器端**只有部分插件**的 client bundle 出现在 HTML 的 plugin manifest 里（`/plugins/??…` 那一串 id 里查不到目标插件），页签/面板不出现；
- 对应插件的 server API 返回 **404**（如 `/context/api/status`、`/guardian/api/state`）；
- 但：`dsh --profile web --dump-config` 里这些插件**行都在**（`- id: … / name: …`）、`cordis.patch.yml` 里**没有** `disabled: true`、插件目录能被 `import()` 成功；
- 实例启动日志**没有任何报错**（§"静默"正是它难查的原因）。

## 根因（2026-09-13 实测定位）

`dshmarket` 插件自己维护了一份插件启停状态：

```json
// <DSH_HOME>/profiles/web/.dsh-market/state.json
{ "disabled": ["dsh-my-context", "dsh-task-reliability", "dsh-ts-example", …] }
```

它会在启动时按这份列表**强制关闭**对应插件，日志落在 `<DSH_HOME>/profiles/web/.dsh-market/log.ndjson`：

```
my-context: patch layer disabled rows my-context
my-context -> off: fiber=false
my-context: off ok=true
```

`verify-real-profile.mjs` 复刻生产 profile 时会**整份复制 profile 目录**（含 `.dsh-market/`）与 `cordis.patch.yml` 的 disabled 行 —— 于是"用户在真实 profile 里禁用过的插件"在隔离实例里**依然被静默关闭**。

## 判定与排除步骤（按序，每步都能独立推翻假设）

1. **先分清"配置层"与"运行时"**：`dsh --dump-config` 有行 ≠ 运行时挂载。判据只看两处：HTML plugin manifest 里有没有该 id、该插件 server API 是否 200。
2. **A/B 对照（决定性）**：把隔离 profile `node_modules/<pkg>` 的软链**指回主工作区（迁移前版本）**重启 → 若"同样缺"，说明与本次改动**无关**；若"主工作区版在、工作区版不在"，才回头查自己的改动。
3. **干净 profile 复现**：`cp -R` 隔离 profile → 把 `cordis.patch.yml` 重写成只有 `- insert: []` → 仍缺 ⇒ 与 patch 行无关。
4. **查 dshmarket**：`cat <DSH_HOME>/profiles/web/.dsh-market/state.json`，看 `disabled` 是否含目标插件；再看 `.dsh-market/log.ndjson` 的 `-> off` 记录。

## 修法

```bash
python3 - <<'PY'
import json, pathlib
p = pathlib.Path('<DSH_HOME>/profiles/web/.dsh-market/state.json')
d = json.load(p.open())
enable = {'dsh-my-context', 'dsh-task-reliability'}   # 本次要验的插件
d['disabled'] = [n for n in d.get('disabled', []) if n not in enable]
p.write_text(json.dumps(d, ensure_ascii=False))
PY
```

然后重启实例（改的是服务端读取的状态文件）。同时把 `cordis.patch.yml` 里对应的 `disabled: true` 行删掉（两处都要）。

## 如何避免误判成插件 bug

- **不要**只用 `dump-config` 或"配置文件里没 disabled"就断定插件会加载；
- **不要**只看初始 DOM 判页签（原生 dockkit 空 pane 不 seed tab；需先触发一次「新标签页/展开」意图）；
- 出现"部分插件静默不加载"时，**先做 A/B 对照**再怀疑自己的改动——这一步能在几分钟内把"我的迁移坏了"排除掉；
- 隔离验证前，把 `.dsh-market/state.json` 的 `disabled` 里目标插件清掉（或整个删掉 `.dsh-market/` 目录）。
