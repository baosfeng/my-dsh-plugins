# 远程控制（dsh-my-remote）

> 源码：`plugins/dsh-my-remote/` · [插件 README](../../plugins/dsh-my-remote/README.md) · [文档索引](../索引.md)

## 功能

离开电脑后，ask（agent 提问）、approval（等待批准）、end（会话结束）事件实时下发到外部通道（手机 / IM / 中转服务）；外部经受鉴权的入站 API 可回答 ask、批准 approval、查询状态、继续会话，会话不再因无人操作而挂起。

## 安装

```bash
dsh plugin --profile web add dsh-my-remote
```

## 关键配置

**设置 → 插件 → 远程控制** 面板可直接编辑 `apiToken`（掩码，留空则不修改）/ `askTimeoutMs` / `approvalTimeoutMs` / `webhooks[]`（列表增删改），保存写回 profile 层 `cordis.patch.yml` 的 `remote` 行并立即生效；也可按下表手写同一行 `config:`：

| 配置键                               | 作用                                                                                           |
| ------------------------------------ | ---------------------------------------------------------------------------------------------- |
| `apiToken`                           | 写指令鉴权，配置后须带 `x-remote-token` 头；留空则仅靠 loopback 围栏                           |
| `askTimeoutMs` / `approvalTimeoutMs` | 等待远程决议超时（0 = 无限）；ask 超时返回空答案由模型自行决策，approval 超时 fail-closed 拒绝 |
| `webhooks`                           | 下行通道列表：名称、URL、事件类型、附加请求头                                                  |

> 面板**不暴露** webhook 的自定义 `headers` 与 `end`/`ask`/`approval` 事件开关（仍在 yml 手写）；保存会先读该行已有配置再合并，不覆盖这些手写项。

## 主要能力

- **事件下行**：ask / approval / end 三类事件帧 POST 到配置的 webhook，含会话 id、标题、问题或原因；
- **指令上行**：`/remote/api/command` 为统一入口，白名单动作 answer / approve / continue，另有状态与审计查询接口；
- **本机优先**：本机先操作则透传原生流程（体验与未装插件一致），远程先到达则短路注入结果；
- **安全模型**：loopback 信任围栏 + token 鉴权 + 动作白名单 + 全量操作审计（含鉴权失败与非法动作），会话结束后未决条目一律 fail-closed 清理，决议条目单次消费防重放；
- **通道可扩展**：事件帧与指令格式渠道无关，微信 / QQ / 飞书机器人只需实现适配器做协议转换，事件层与指令层零改动。
