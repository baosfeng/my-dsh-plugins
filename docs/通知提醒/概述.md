# 通知提醒（dsh-my-notify）

> 源码：`plugins/dsh-my-notify/` · [插件 README](../../plugins/dsh-my-notify/README.md) · [文档索引](../索引.md) · 设置页定稿原型：[简版 v1](../原型重构/notify-simple-v1.html)（历史存档：[v2](../原型重构/dsh-my-notify-v2.html)）

## 功能

会话（本轮对话）结束、agent 询问问题、等待用户批准时推送系统通知 + 页面 toast + 提示音，点击通知跳到对应会话；并支持远程 hook 触发与出站 webhook（企微 / 飞书 / 钉钉 / 通用中转，飞书支持 interactive 卡片）。通知文案按事件独立模板化，模板可引用 32 个变量。

## 安装

```bash
dsh plugin --profile web add dsh-my-notify --trust-lockfile
```

## 架构

server 端只读观察宿主事件，统一渲染文案后分两路输出（SSE 广播、出站 webhook）；client 端只做呈现。

| 模块 | 职责 |
| ---- | ---- |
| `src/index.ts` | 装配：配置规整 → 通知总线 / 路由 / 监听；统一出口做子代理过滤、免打扰、文案渲染后再分发两条通道 |
| `src/listeners.ts` | 监听 `agent/status` / `tools/pre-execute` / `approval/request`，waterfall 一律透传 `next()` |
| `src/session.ts` | 顶层会话判定（header / `subagentDepth` / `parentSession` 三层标记）、标题、ask 问题摘要 |
| `src/token-meter.ts` | 会话 token 计量（输入 / 输出 / 缓存 / 推理 / 请求数），供 `tokens.*` 变量 |
| `src/notice.ts` | 通知总线：SSE 客户端集合 + 同类去重窗口 + 心跳 |
| `src/routes.ts` | `/notify/api` 路由：stream / trigger / info / config / webhooks / variables / preview |
| `src/notify/vars.ts` | 变量目录与取值（`VAR_GROUPS`）+ 旧语法别名表 |
| `src/notify/template.ts` | 单次扫描渲染，新旧语法共存，未识别占位符原样保留 |
| `src/notify/defaults.ts` | 五类事件默认文案与广播前渲染（空串回退默认） |
| `src/notify/channels.ts` | 各渠道消息组装（含飞书卡片入口与卡片字段短键映射） |
| `src/notify/card.ts` | 飞书 interactive 卡片构建、配色、@ 行、19.6KB 截断 |
| `src/notify/config.ts` | 高级配置默认值与逐字段 fail-open 规整 |
| `src/webhook/` | 渠道适配与签名（秒级时间戳）+ 推送调度（每 webhook 独立重试） |
| `src/webhook-store.ts` | webhook 列表与失败记录的 JSON 持久化 |
| `src/client/` | 设置页简版单页（事件 → 文案 → 飞书卡片 → 送达，渠道 / 呈现 / 高级进「更多设置」抽屉）、SSE 订阅、系统通知 / toast / 提示音呈现 |

## 配置落点

- **嵌套配置**（`sound` / `toast` / `system` / `messages`）与免打扰在 profile patch 文件里以 JSON 串 / 扁平字段持久化，由 `src/index.ts` 的 `buildOptions` 解回；
- **webhooks** 是对象数组，独立存 `<profile>/notify-webhooks.json`（失败记录同处）；`cordis.patch.yml` 显式配置的 `webhooks` 优先；
- **localStorage** 只存运行时闸门（`dsh-notify:{notify,sound,toast,volume,tone}`）与客户端去重时间戳，进设置页时若本地键缺失则按配置播种；
- 字段与默认值逐项见 [插件 README · 配置](../../plugins/dsh-my-notify/README.md#配置)（唯一维护处）。

## 路由

| 方法 | 路径 | 用途 |
| ---- | ---- | ---- |
| GET | `/notify/api/stream` | SSE 长连接（心跳 + 断线 3s 重连） |
| POST | `/notify/api/trigger` | 远程触发（`x-notify-token`，显式 title / body 优先） |
| GET | `/notify/api/info` | 触发开关与去重 / 免打扰状态（token 只暴露是否启用） |
| GET / PUT | `/notify/api/config` | 当前配置读取 / 保存（保存后失效客户端运行时缓存） |
| GET | `/notify/api/webhooks` | webhook 列表 + 失败记录 |
| GET | `/notify/api/variables` | 变量目录（分组 / 名称 / 说明 / 示例） |
| POST | `/notify/api/preview` | 按 `kind` / `channel` / `sample` / `card` 渲染一次，返回 `{card, text, vars}` |

全部先过 loopback 信任围栏。

## 变量系统

`{{namespace.var}}` 分 7 组共 32 个（session 11 / event 4 / ask 3 / tool 1 / approval 2 / tokens 8 / notify 3）；旧 `{var}` 7 个别名同值生效。完整清单见 [插件 README · 变量](../../plugins/dsh-my-notify/README.md#变量)。

## 渠道能力矩阵

| 渠道 | text | markdown | post | interactive 卡片 | 加签 |
| ---- | ---- | -------- | ---- | ----------------- | ---- |
| wecom | ✅ | ✅ | — | — | sha256，时间戳秒级 |
| feishu | ✅ | — | ✅ | ✅（schema 2.0 / 1.0） | hmac-sha256 + base64，秒级 |
| dingtalk | ✅ | ✅ | — | — | hmac-sha256 + base64，秒级 |
| generic | ✅（原始通知帧 + 渲染后 `message`） | — | — | — | 不签名 |

卡片能力只在飞书生效：按事件配色、字段区（≤10）、`open_url` 按钮、@ open_id / user_id（≤20，空项剥离）、整卡 19.6KB 截断 + 续行提示、元素上限 200。

## 主要行为

- **子代理过滤**：`end` 通知默认只推顶层；`subagentEnd` 开启后子代理帧才放行，过滤在统一出口执行，SSE 与 webhook 一致；
- **免打扰**：命中时段静默所有通道（含远程触发）；
- **去重**：服务端按 `kind:sessionId` 在 `dedupeMs` 内去重，客户端再用 2 秒窗口 + Web Locks 保证同一帧只弹一次；
- **降级**：配置坏字段回退默认值、通知权限被拒走 toast、配置接口不可达时 toast 用内置默认值，均不打断通知路径。
