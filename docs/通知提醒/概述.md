# 通知提醒（dsh-my-notify）

> 源码：`plugins/dsh-my-notify/` · [插件 README](../../plugins/dsh-my-notify/README.md) · [文档索引](../索引.md)

## 功能

会话（本轮对话）结束、agent 询问问题、等待用户批准时推送系统通知 + 提示音，点击通知跳到对应会话；并提供远程 hook 触发接口与出站 IM 机器人推送。

## 安装

```bash
dsh plugin --profile web add dsh-my-notify --trust-lockfile
```

## 关键配置

设置 → 插件 → 通知提醒 页签可视化编辑，也可写在 profile patch 的插件 config 中：

- `end` / `ask` / `approval` / `subagentEnd`：四类触发开关（子代理完成默认关，开启后标题带「子代理」前缀）；
- `apiToken` / `dedupeMs` / `askMode` / `webBaseUrl`：远程触发鉴权、同类去重窗口、ask 推送完整还是摘要、会话链接基址。

## 主要能力

- 事件源为 agent 状态转为空闲、ask 工具调用、待批准请求，全部只读观察并透传，不干扰原生流程；
- 浏览器侧走 SSE 长连接（心跳、断线重连、多标签页共享），系统通知 + 滴声 + 页面 toast 兜底；
- 出站机器人推送（企微 / 飞书 / 钉钉）按渠道格式化与签名，失败重试并记录；
- 远程触发接口受 loopback 信任围栏保护，配置 token 后可远程主机 / cron / CI 调用。
