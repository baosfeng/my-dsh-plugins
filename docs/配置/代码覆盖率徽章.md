# 代码覆盖率徽章配置

本仓库接入 Coveralls，README 显示实时覆盖率徽章。

## 配置

1. 用 GitHub 账号登录 [coveralls.io](https://coveralls.io) 并授权 `baosfeng/my-dsh-plugins` 仓库（Coveralls 会自动检测并启用）。
2. README 中的徽章：

```markdown
[![Coverage Status](https://coveralls.io/repos/github/baosfeng/my-dsh-plugins/badge.svg?branch=main)](https://coveralls.io/github/baosfeng/my-dsh-plugins?branch=main)
```

颜色含义：绿色 ≥ 90%、黄色 80–89%、红色 < 80%。点击徽章可看整体趋势、各插件详情与文件级热图。

## 覆盖率口径

- 由 vitest + `@vitest/coverage-v8` 生成，配置在各插件的 `vitest.config.mjs`（根配置 `vitest.config.mjs`）。
- **阈值：行 ≥ 85% / 分支 ≥ 75% / 函数 ≥ 80%**；覆盖范围仅统计 server 端 `lib/index.js`（client 端无法统计，豁免）。
- 数据由 CI 的 `test` job 上传，`coverage-finish` job 汇总。

## 故障排除

| 现象               | 排查                                                                                                                 |
| ------------------ | -------------------------------------------------------------------------------------------------------------------- |
| 徽章显示 `unknown` | CI workflow 是否成功；Coveralls 是否已授权仓库；Actions 日志里的覆盖率上传步骤                                       |
| 覆盖率数据不更新   | `test` job 的 `Upload coverage to Coveralls` 步骤是否成功；`coverage-finish` job 是否运行；在 Coveralls 网站手动刷新 |
| 单个插件覆盖率缺失 | 该插件测试是否成功；`coverage/lcov.info` 是否生成；该插件 `vitest.config.mjs` 的覆盖率配置                           |

相关文件：`.github/workflows/ci.yml`（上传步骤）、`vitest.config.mjs`、各插件 `vitest.config.mjs`、`README.md`（徽章位置）。
