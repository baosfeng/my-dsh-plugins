# 代码覆盖率徽章配置

## 概述

本仓库已集成 Coveralls 代码覆盖率服务，README 中会显示实时覆盖率徽章。

## 配置步骤

### 1. 注册 Coveralls

1. 访问 [coveralls.io](https://coveralls.io)
2. 使用 GitHub 账号登录
3. 授权访问 `baosfeng/my-dsh-plugins` 仓库
4. Coveralls 会自动检测到仓库并启用

### 2. 验证配置

配置完成后，Coveralls 会：

- 在 CI 测试完成后自动接收覆盖率数据
- 为每个插件单独跟踪覆盖率
- 汇总所有插件的总覆盖率并显示在徽章上

### 3. 徽章说明

README 中的覆盖率徽章：

```markdown
[![Coverage Status](https://coveralls.io/repos/github/baosfeng/my-dsh-plugins/badge.svg?branch=main)](https://coveralls.io/github/baosfeng/my-dsh-plugins?branch=main)
```

徽章颜色含义：

- 🟢 绿色：覆盖率 ≥ 90%
- 🟡 黄色：覆盖率 80% - 89%
- 🔴 红色：覆盖率 < 80%

### 4. 覆盖率报告

覆盖率报告由 vitest + @vitest/coverage-v8 生成，配置在各插件的 `vitest.config.mjs` 中：

- 覆盖率阈值：行≥85% / 分支≥75% / 函数≥80%
- 覆盖范围：仅统计 server 端 `lib/index.js`（client 端因无法统计而豁免）

### 5. 查看详细报告

点击徽章可跳转到 Coveralls 页面查看：

- 整体覆盖率趋势
- 各插件覆盖率详情
- 文件级别覆盖率热图
- 历史覆盖率变化图表

## 故障排除

### 徽章显示 "unknown"

1. 确认 CI workflow 运行成功
2. 检查 Coveralls 是否已授权仓库
3. 查看 GitHub Actions 日志中的覆盖率上传步骤

### 覆盖率数据不更新

1. 确认 `test` job 中的 `Upload coverage to Coveralls` 步骤成功
2. 检查 `coverage-finish` job 是否运行
3. 在 Coveralls 网站手动刷新数据

### 单个插件覆盖率缺失

1. 确认该插件的测试运行成功
2. 检查 `coverage/lcov.info` 文件是否生成
3. 查看该插件的 `vitest.config.mjs` 覆盖率配置

## 相关文件

- `.github/workflows/ci.yml` - CI 配置（覆盖率上传步骤）
- `vitest.config.mjs` - 根级覆盖率配置
- `plugins/*/vitest.config.mjs` - 各插件覆盖率配置
- `README.md` - 徽章显示位置
