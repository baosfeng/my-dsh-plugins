## 一、设置页「全局提示词」分区

- [ ] **分区存在**：设置 → 插件 → 「记忆」页里出现**独立分区「全局提示词」**，与「全局记忆」「项目记忆」分区**视觉上并列且分离**（不同区块，不是混在记忆列表里）
- [ ] **新增**：填标题 + 正文 → 保存（绿色确认 UI）→ 列表出现该条，刷新浏览器仍在
- [ ] **编辑**：点编辑改标题与正文 → 保存 → 列表与落盘文件均为新内容（旧内容不残留）
- [ ] **删除**：点删除 → 弹**红色二次确认** → 确认后条目消失；取消则不删
- [ ] **启停**：切某条开关 → 开关状态立即变化（`enabled` 翻转，**条目不删除**），再切回来恢复正常
- [ ] **上移下移**：新增第 2、3 条 → 用上移/下移改变顺序 → 列表顺序即时更新；首条「上移」与末条「下移」不可用或无效（不报错、不越界）
- [ ] **顺序即注入顺序**：把某条移到最前 → 下一轮注入里它出现在最前（见第三节）

## 二、存储与隔离（与全局记忆完全隔离）

- [ ] **存储文件不同**：`ls $DSH_HOME/memory/prompts.json` 存在；提示词**不在** `$DSH_HOME/memory.json` 里（后者只有记忆条目）；`$DSH_HOME/memory/candidates.json` 只放候选
- [ ] **UI 分区不同**：见第一节第一条（「全局提示词」不是记忆列表的一部分）
- [ ] **端点独立**：`curl -s http://127.0.0.1:3099/my-memory/api/prompts` → 返回提示词列表；记忆端点返回的内容**不含**提示词
- [ ] **`memory_query` 输出不含提示词**：让 agent 调 `memory_query`（scope 全局 + scope 项目各一次）→ 输出**只有记忆条目**（带分类 / id），**没有任何提示词条目**
- [ ] **无 agent 写工具**：agent 工具列表里**只有** `memory_query` / `memory_save` / `memory_delete` —— 没有任何「写提示词」的工具（提示词只能人工在设置页改）
- [ ] **互不影响**：删掉一条提示词 → 全局记忆条数不变；删掉一条全局记忆 → 提示词条数不变

## 三、注入生效（保存后下一轮即生效，无需重启）

- [ ] **启用即注入**：新增一条正文为可识别串（如 `PONG-PROMPT-1`）的提示词并启用 → **不发重启**、直接发下一条消息 → 该串出现在模型收到的系统提示里
- [ ] **全量按序、不评分不截断**：连续新增 3 条启用提示词 → 三条**全部**出现在系统提示里（不被 top-N 挤掉），顺序与设置页一致
- [ ] **编辑后下一轮生效**：改正文为新串 → 下一条消息里是新串，旧串消失
- [ ] **禁用即不注入**：关掉某条 → 下一条消息的系统提示里**该条消失**，其他条不受影响
- [ ] **全部禁用时无残留**：把**所有**提示词禁用 → 系统提示里**没有任何**提示词内容（无空标题、无空 section 残渣）；设置页条目仍在（只是不注入）
- [ ] **重启后一致**：重启隔离实例 → 启停状态 / 顺序 / 正文与重启前一致（防抖 300ms + 原子写已落盘）

## 四、种子迁移（内置「中文思考」）

- [ ] **首启写入种子**：全新 `DSH_HOME`（`$DSH_HOME/memory/prompts.json` 不存在）首启 → 文件里出现 `builtin: "builtin:think-zh"`、标题「中文思考」、`enabled: true`，设置页列表可见且带**内置徽标**
- [ ] **种子默认启用并注入**：该条默认启用 → 中文思考指令出现在系统提示里（替代已下线的 `dsh-think-zh-expand`）
- [ ] **删除后不复活**：删掉种子条 → 重启实例 → **不重新出现**（`prompts.json` 已存在即不补种）
- [ ] **清空也不补种**：把提示词全部删光（文件存在但 items 为空）→ 重启 → 仍为空，不复活
- [ ] **可停用**：种子条可被停用 / 编辑 / 删除（不是只读项）

## 五、上限行为

- [ ] **条数上限 20**：新增到第 20 条正常；第 21 条被拒绝并给出明确提示（不静默丢弃、不写入）
- [ ] **单条正文上限 1000 字**：正文输入 > 1000 字 → 保存时**截断 + warn 提示**（面板可见）；注入内容也是截断后的
- [ ] **注入上限不静默**：启用条数超过 `maxPromptItems` 时 → 超出部分不注入**且有 warn**（不是无声少注入）
- [ ] **配置可调**：patch 里把 `maxPromptItems` / `maxPromptLength` 改小（如 2 / 20）→ 重启后上限按新值生效（超限行为同上）

## 六、记忆能力未被破坏（回归）

- [ ] **全局记忆注入仍正常**：全局记忆照旧在会话开始注入，条数与长度受 `maxItems` / `maxDescLength` 限制（提示词不占这些名额）
- [ ] **写操作确认矩阵仍生效**：`saveApproval=auto` 下，workspace-write 会话保存记忆弹确认、danger-full-access 会话免确认（与改动前一致）
- [ ] **记忆面板无回归**：全局 / 项目分区、新增 / 修改 / 删除、候选区显示与改动前一致
- [ ] **Console 干净**：整轮走查 Console **无未捕获异常**；提示词 section 注册失败时日志有明确降级提示（记忆能力不受影响）
